# 企业产品场景与验收契约

日期：2026-10-20。状态：目标契约 v1；实施状态由[缺口台账](../audit/现状与功能缺口.md)与[验证记录](../quality/验证证据与测试隔离.md)记录。关联 ENT-01～18。

最新组织、审核、直接申报、删除项目/活动关联、统一退回及公式导出以[学院职责与统一审核规范](学院职责与统一审核规范.md)和ADR0005为准。下方三角色及旧单级审核仅为历史设计对照，不作为新开发授权；现有通过记录不能替代新流程验证。

## 组织与授权

单个部署服务一个办学组织，不引入多租户、公开注册或收费。ADMIN、PUBLISHER、STUDENT 是服务端固定能力角色，显示名称可配。组织目录为院系→专业→班级，也允许管理员维护其他不循环的分组。归属使用稳定 ID，名称只用于展示。学生有学号及有时间区间的归属；周期开启时固定适用学生清单，后续转班不静默改写本期归属或排名。

| 操作 | 管理员 | 活动发布者 | 学生 |
|---|---|---|---|
| 周期、方案、制度模板、组织、站点设置 | 全部，写入重新鉴权 | 只读已生效的业务说明 | 只读本人适用规则 |
| 账号建号、导入、停用、重置 | 允许，不能停用/降级自身 | 禁止 | 禁止 |
| 学生档案 | 全部；导出须另审计 | 本人活动名单内最小字段，不开放全校档案 | 本人 |
| 活动浏览 | 全部 | 本人负责的活动；目录的公开业务信息 | 本周期可申报活动 |
| 活动维护、名单认定 | 全部 | 本人负责的活动 | 禁止维护；可提交本人来源 |
| 分值确认、认定审核、成绩扣分 | 允许 | 禁止审核自身提交，默认无审核权 | 禁止 |
| 材料下载 | 业务权限内 | 本人上传或本人活动引用 | 本人上传或本人事实引用 |
| 结果、确认、异议 | 全部；不能替学生确认 | 默认无成绩访问权 | 本人；提交本人确认/异议 |
| 排名、导出 | 全部授权范围 | 默认禁止 | 默认只见本人名次；公开名单由明确设置控制 |
| 审计、重开、备份 | 管理员；恢复为运维命令 | 禁止 | 只见本人相关处理历史 |

服务授权在 Route Handler 和事务内复查，页面隐藏入口不构成授权。不存在或无权访问的私有对象对外统一 404；明确角色不符返回 403。初始密码未改时只可访问改密、退出和会话必要接口。关键操作必须给业务理由，后台不从客户端接受 actorId、最终分数或权限范围。

## 端到端场景与可验收标准

| 需求 | 用户流程与成功标准 | 失败/并发验收 |
|---|---|---|
| ENT-01 | 运维一次初始化→管理员建号→本人首次改密→重新登录；退出/停用/重置立即撤销旧会话 | 双初始化只成功一次；错误密码反馈不泄漏账号存在性；重放旧 cookie 写入失败 |
| ENT-02 | 管理员建组织、建学生、导入名单、查看差异、确认、修正归属；学号保留前导零 | 重复不同资料阻断；同资料跳过且不改密码；组织循环/有引用删除失败；旧 revision 409 |
| ENT-03 | 创建周期→配置适用学生与唯一方案匹配→预检→开启；新转入学生通过有理由的范围变更纳入 | 无匹配、多匹配、无学生、非法评分树阻断开启；班级改名不改变固定范围 |
| ENT-04 | 从空白/可选学校模板建立制度→增删移复制树→定位错误→逐层试算→保存草稿 | 循环、错误百分比、无效折算与精度返回字段定位；离开未保存页面需确认 |
| ENT-05 | 派生更正版本→检查全部引用→给迁移映射→预览人数和分差→准备候选→原子生效 | 预览后任何相关输入/范围变化拒绝；故障保留旧集；并发只一个生效；重试不双迁移 |
| ENT-06 | 发布者维护活动→管理员确认分值→学生看完整内容和时间→申请认定 | 越权改活动失败；已确认分值不能普通保存绕过影响分析；结束早于开始被拒 |
| ENT-07 | 学生/组织提交同一活动事实及材料→审核→退回补充/驳回→重新提交；个人项目由管理员定义规则 | 一学生一活动一事实，多来源通过只计一次；提交者不能自审；旧 revision 拒绝；材料不属于提交者拒绝 |
| ENT-08 | 选文件→显示实际文件名/大小→上传→关联来源→授权下载 | 超限、中断、格式伪造、路径穿越、无权引用、哈希不符均拒绝；清理不删除已引用材料 |
| ENT-09 | 选学生/模块→读取当前值→填写新值和理由→差异保存；扣分可撤销 | 必需缺失显示缺失，0为有效；覆盖不累加；正扣分额×制度系数；撤销保留历史 |
| ENT-10 | 下载版本模板→文本学号→列映射→逐行预检→确认→取得真实处理结果 | 所有导入错误整批回滚；预览15分钟过期；提交只认服务端 batchId；旧批次不重新交付初始密码 |
| ENT-11 | 学生查看本人分数、缺失、活动和每层计算；管理员按学生/组织/完整性查询 | 学生改 URL 无法见他人；展示规则、输入和结果身份；没有完整成绩时 total=null |
| ENT-12 | 管理员生成完整候选并发布核对→学生绑定该结果确认/异议→管理员处理并关联更正→重发布 | 输入变化使候选过期；新结果哈希变化后旧确认无效；异议不能由简单改状态绕过事实更正 |
| ENT-13 | 选择固定排名组→显示范围与并列策略→导出同一结果集 | 不完整成绩无名次；默认按最终两位分数竞赛排名 1,1,3；同分二级排序只稳定行序；公式文本安全 |
| ENT-14 | 检查待审/缺失/未决异议/确认政策→锁定快照→理由重开→更正并重新发布/锁定 | 锁定后所有计分写入阻断；重开不修改旧快照；账号/品牌改名不改变历史导出 |
| ENT-15 | 管理员按时间/操作者/动作/对象查询审计；学生看本人待办和处理通知 | 业务写入与审计同事务；不记录密码、令牌和材料正文；通知重试去重，读取他人失败 |
| ENT-16 | 设置草稿→本页真实预览→发布→刷新跨会话生效→恢复历史值为新修订 | 非管理员拒绝；旧 revision 409；恶意 URL/图标/HTML 被拒；外观前后同一历史结果哈希一致 |
| ENT-17 | 桌面和手机完成前述完整流程；手机可读文字导航，评分按目录逐项编辑，导入分步 | 320～1440px 无整页溢出；键盘弹窗焦点/关闭/错误恢复可用；不以隐藏关键数据通过检查 |
| ENT-18 | 数据库迁移→生产构建→实际生产进程→健康/重启→备份→隔离恢复→一致性报告 | 未经实测不得宣称上线；恢复失败不覆盖源库；Docker 部署保持暂缓 |

## 生命周期及更正语义

周期 CONFIGURATION→ACTIVE→CHECKING→LOCKED。CONFIGURATION 允许规则/范围草稿；开启后固定范围和已生效规则。ACTIVE 允许事实录入；CHECKING 冻结普通写入，管理员通过理由更正入口录入并生成新结果，旧发布仍可追溯但标记被替代。LOCKED 只读，必须以独立重开记录转回 ACTIVE，再完成发布核对和锁定。不能直接把 phase 更新为 LOCKED 当作结算。

认定来源 DRAFT→PENDING→APPROVED/REJECTED/NEEDS_CHANGES；PENDING 可本人撤回；NEEDS_CHANGES 补材料生成新提交修订；APPROVED 撤销须管理员理由与影响预览。事实有效性取任意有效 APPROVED 来源，不按来源份数累计。个人项目使用项目规则稳定 ID 与发生日期/业务事实键；冲突由管理员核对合并，文件哈希不能自动判事实重复。

## 可配置政策与安全默认

这些是产品安全默认，不冒称学校已批准制度。周期开启前由管理员明确确认：默认只用一个全范围方案；启用多方案时范围必须互斥且穷尽；排名按最终两位竞赛排名；学生只见本人名次；所有必需成绩齐备、待审处理完、未决异议为0才可锁定；是否要求全员确认默认开启；申报窗口由周期日期控制，未配置不自动替用户设截止日。保留期限、RPO/RTO、实际容量及是否分级审核须组织核准，未核准不自动删除历史或承诺容量。

功能边界：不提供任意 JS/SQL/HTML、脚本公式或未经验证的外部资源；结构与算子受 schema 约束。学校模板仅可选示例。新增算子必须补数学定义、精度、缺失政策、迁移与回归数据。
