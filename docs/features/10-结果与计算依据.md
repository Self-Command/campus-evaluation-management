# 结果查询与计算依据

日期2026-10-20；ENT-11/05；目标详细设计v1。当前getStudentResult只在ACTIVE即时计算，无发布结果集。

学生默认查看当前周期本人结果，管理员按学生/组织/完整性分页查询，发布者无成绩查看权。结果头显示周期阶段、规则版本、输入修订、结果集身份和生成/发布时间；即时结果清晰标为当前成绩，已发布结果另有固定身份，不能把即时值说成已发布。不存在完整成绩时总分显示“待补齐”，total=null；provisionalTotal仅供核对，不能进入正式排名。

明细按树展示每节点原始汇总→封顶→折算→扣分→下限→父级贡献，来自Rational精确中间值，最终half-up两位。点击节点查看活动唯一事实、通过来源、成绩输入、扣分项目与理由；来源数量不乘分。没有活动的ACTIVITY按0，不等于必需GRADE缺失。深树使用目录定位和分段显示，不构造递归调用导致栈溢出。

目标计算输入固定在CalculationInput，包含对应SchemeVersion、ScopeSnapshot与InputBasis；运行不从变化的当前表边算边读。结果集所有成员准备完成并验证计数/hash后才可设current；任何失败保留上一完整集。个人项目有效事实也进入同一输入构建器，禁止页面/导出另算公式。

API目标GET /api/results?termId&studentId/resultSetId、GET /api/results/{id}/basis、POST /api/terms/{id}/calculations、GET /api/calculations/{id}。管理员查看具体学生与scope必须服务端鉴权；学生参数studentId与本人不同拒绝。无发布集可看授权即时结果，但确认/排名/锁定必须绑定完整固定集。

桌面概要+树目录+选中节点依据，手机概要→模块卡片→节点详情，避免整张计算表横向拖动才能看关键值。验收RESULT-01本人隔离、RESULT-02精确顺序、RESULT-03多来源唯一计分、RESULT-04缺失、RESULT-05候选中断不切换、RESULT-06固定依据复现、RESULT-07旧结果与当前外观分离。
