# 审计、业务通知与统一检索

日期2026-10-20；ENT-15；目标详细设计v1。当前写审计基础存在，查询/通知尚未完成。

管理员审计入口支持时间范围、动作、操作者、对象类型/ID、requestId，稳定倒序分页；详情展示安全的前后值、理由和关联版本/批次。非管理员无全站审计接口。个人业务处理历史从ReviewEvent与安全摘要读取，不能把全站AuditEvent原JSON返回学生。审计与业务事务同成同败，禁止业务成功后异步“尽力”记关键审计。

动作覆盖初始化、登录/撤销、账户改动、周期/范围、规则保存/生效、活动确认/更正、来源提交/审核/撤销、成绩/扣分、导入、发布/确认/异议、锁定/重开、设置发布、导出、恢复。失败登录/异常为安全日志，记录requestId与稳定码，不记密码、token、材料正文或未经脱敏整份名单。

站内通知只服务真实业务：待处理认定、退回材料、结果发布、异议结论、周期截止变更。Notification按recipient+dedupeKey去重，与业务同事务写；读取通知仍需验证对象权限，权限变更后通知不能提供数据旁路。已读操作只本人，可重复调用；默认不扩展邮件/短信或消息服务。

列表筛选统一q≤80、page/pageSize、可读空态和一键清筛选；跨对象搜索仅返回当前角色可访问的最小摘要。批量操作固定ID/revision集合、最大100，后台重新鉴权，任一失败整批回滚；长任务单独返回202和进度，禁止隐藏部分成功。

API目标GET /api/audit-events、GET /api/notifications、POST /api/notifications/{id}/read。审计存储追加，保留期限待组织核准，未核准不自动清除；日志归档/导出须访问控制与hash清单。验收AUD-01关键操作覆盖、AUD-02回滚无孤立成功日志、AUD-03敏感脱敏、AUD-04筛选索引、AUD-05通知去重/他人读取拒绝、AUD-06批量原子性。
