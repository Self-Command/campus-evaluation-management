# 账号、组织与学生档案

日期2026-10-20；ENT-02/10；目标详细设计v1；现有accounts及account-import可复用，组织实体未实现。

管理员“人员与组织”按账号、学生、组织分视图。列表搜索账号/姓名/组织，固定排序与分页；详情展示最小身份信息、状态、归属和更正历史。新建对话框随role显示学生必填项；保存成功才展示一次性凭据，可复制并关闭清除本地状态。修改需revision+理由，不能编辑已有学生学号；不能停用或降级自己；密码重置不用于修改本人密码。

组织创建必须选父级类型，代码唯一，路径无环；改名只变展示，固定周期范围不随当前名变化。学生转班先结束旧Membership再建新Membership，区间不能交叠；如影响已开启周期，单独发起范围变更预览，不静默改排名。组织有历史引用只能停用。角色从学生改为其他角色不删除档案和历史事实；新的学生操作只接受role=STUDENT且有效档案。是否允许长期跨角色保留档案在审计中可见。

API沿用GET/POST /api/admin/accounts、PATCH /api/admin/accounts/{id}、POST reset-password、GET /api/students/{id}；目标组织GET/POST /api/organizations、PATCH /api/organizations/{id}，学生归属POST /api/students/{id}/memberships。当前固定20条分页保留兼容，目标增加pageSize与组织ID筛选。发布者不能遍历全校学生；本人活动名单仅返回姓名、学号及必要班级。

并发使用账户管理锁、对象revision与唯一约束；同账号重复建号409，事务不留半份档案。导入只新增学生，已有相同跳过不重置密码，不同阻断全批。账号停用和改角色递增authVersion并撤销会话；资料改名递增revision，历史快照保留当时值。

手机列表为含姓名/学号/角色/状态的卡片，筛选独立面板，详情分组展示；编辑弹窗可滚动、底部保存始终可达。验收ACC-01前导零、ACC-02重复/缺字段原子性、ACC-03自身保护、ACC-04旧revision、ACC-05组织环/区间重叠、ACC-06转班历史不变、ACC-07三角色越权及一次性交付。
