# 管理员设置中心

日期2026-10-20，最后更新2026-10-24；ENT-16/17。当前已有SiteSettings/BrandAsset，采用GET/PUT `/api/admin/settings`直接保存生效，revision、理由、白名单、资源引用及审计均在事务内复核。下文草稿审批、分享及任意导航定制属于延后目标，不能用它们判断当前页面尚无保存能力。

本轮实际范围：站点名称1–40、说明1–160、页面标题1–80字符；主题九种预设及站点默认深浅模式；Logo/favicon/登录背景独立资源；Logo显示尺寸16–128像素；登录公告0–200字符。登录失败限制三字段loginFailureLimitEnabled默认false、loginFailureMaxAttempts默认5（1–100整数）、loginFailureLockMinutes默认15（1–1440整数），旧设置缺失字段可直接读取。修改登录策略清除旧临时锁定；保持旧密码与已登录会话。理由2–500字符，保存同时提交全部页签草稿；上传回调不覆盖其他草稿，保存失败保留输入，成功保持反馈并应用最新品牌主题。来源为指定模板完整invoice表单/预览，见[来源清单](../design/模板来源与适配清单.md)、[本轮验证](../audit/周期制度与登录设置实施验证-2026-10-20.md)及[登录页与主题个性化实施验证](../audit/登录页与主题个性化实施与验证-2026-10-24.md)。

## 当前设置页签与真实能力

| 页签 | 已实现字段与操作 |
|---|---|
| 品牌与标题 | 站点名称、站点说明、页面标题 |
| 标识与主题 | Logo、favicon；Logo 显示尺寸 16–128（默认 28，侧栏折叠上限 32）；站点默认主题风格（九种预设）与默认深浅模式（浅色/深色/跟随系统） |
| 登录页 | 登录背景上传/更换/移除（PNG/JPEG/WebP，≤5MB，≤8192×8192），16:9 实时预览；登录公告（纯文本，≤200 字符） |
| 登录安全 | 失败限制开关、最大尝试次数、锁定时长 |
| 活动附件 | 活动附件数量、单文件大小、允许后缀 |

- 保存仍为整页提交全部页签草稿，必须填写理由并携 `revision`；保存失败保留输入，成功后回读最新设置。
- `GET /api/settings/public` 只返回品牌、默认主题、背景资源 ID 与公告的显式白名单，不返回登录策略、附件策略、修订号或审计信息。
- 登录背景上传使用 `x-asset-kind: login-background`；站点标识与登录背景分别校验格式、体积和尺寸，保存时复核引用资源存在且类型匹配。
- 登录页与改密页共用认证外壳；所有角色可在登录前和登录后调整个人深浅模式与主题风格，个人偏好存于当前浏览器 cookie（365 天），管理员默认值只影响未设置个人偏好的浏览器。
- 管理员自己的个人主题选择同样只影响当前浏览器，不改变站点默认；修改站点默认仍需在设置页保存。
- 2026-10-24 本地验收完成：类型检查、Lint、136 项集成测试、独立 standalone HTTP 检查（85 个角色页面、20 个静态资源、活动参与/申报到结算闭环）和浏览器截图检查均通过，详见实施验证记录。

## 延后目标

以下为尚未实施的设置扩展，首次交付以现有白名单和本轮方案为准。

设置分品牌与标题、公开分享、主题与导航、业务展示、模板说明；运行密钥/数据库连接不放业务页面。ADMIN写入，三角色只读已发布的必要展示字段，公开登录只拿公开子集。修改草稿不会影响正在使用的站点；当前页面预览采用同一正式组件和受校验值，预览状态不向普通用户展示开发标记。

DRAFT→PUBLISHED→SUPERSEDED；保存草稿携baseVersion/revision，发布锁内校验并递增版本，旧修订409。历史恢复复制旧content生成新草稿，经预览再发布，不修改历史修订。恢复默认同样作为新修订，不删除品牌历史。发布后服务端按version读取/失效缓存，跨会话刷新立即一致，不能只改localStorage。

Logo/favicon/分享图为独立BrandAsset上传，PNG/JPEG/ICO白名单、尺寸/体积校验；禁止SVG/任意外链/脚本，图标从受控组件键列表映射。主题为预设语义token组合，不接受任意CSS。导航标签可改，角色和目标路由固定，不能改文案得到权限。私有页面始终noindex，SEO配置不能把学生姓名/分数写公开metadata。

API目标GET /api/settings/public、GET/PUT /api/admin/settings/draft、POST /api/admin/settings/publish、GET /api/admin/settings/history、POST /api/admin/settings/restore、POST /api/admin/brand-assets。字段错误返回path，资源引用验证必须在发布内再次执行。审计仅安全字段差异，不写secret。外观字段与计分规则完全分离。

手机按设置分组导航→单组编辑→保存→预览→发布，顶部保留当前版本和未保存状态，长站名/导航不挤压按钮。验收SET-01非管理员拒绝、SET-02冲突/草稿隔离、SET-03跨会话生效、SET-04恶意输入、SET-05metadata/favicon真实响应、SET-06恢复生成新版本、SET-07同历史成绩hash不变。
