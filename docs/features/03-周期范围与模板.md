# 测评周期、范围与模板

日期2026-10-20；ENT-03/04/14；目标详细设计v1。当前仅创建、保存配置和开启。

管理员创建周期填写名称、起止/申报/核对时间、适用学生和方案；日期未设不编造。先选空白或制度模板；学校模板以可选示例呈现。复制模板/周期只复制规则和业务政策，不复制学生成绩、审核、确认与附件。制度模板有版本和启停，引用后不联动已生效版本。

预检列出学生总数、每方案人数、未匹配/多匹配/停用账号/非法规则/日期问题。开启时以同一事务固定ScopeSnapshot与SchemeVersion，并设置ACTIVE；检查revision和所有预检基线。若人数很大先准备候选范围，再短事务校验并切换。多方案范围必须互斥穷尽，不采用隐含“最具体优先”。现有学期对全部有效学生的隐含适用在回填时明确列清单，不改变已存事实。

CONFIGURATION只编辑草稿；ACTIVE录入审核；CHECKING只允许受控更正，普通录入409；LOCKED只读。发布转CHECKING必须完整结果集，锁定须通过质量检查并保存快照；重开须理由与旧快照关联。所有状态按钮仅展示后端已具备转换，不以枚举冒充功能。

API：现有GET/POST /api/terms与scheme action；目标GET/PATCH /api/terms/{id}、POST /api/terms/{id}/scope-preview、POST /api/terms/{id}/activate、GET/POST /api/scheme-templates、POST /api/scheme-templates/{id}/copy。开启只携previewId/revision，不能信任客户端人数或scheme匹配结果。目标范围变化走同规则变更的预览/重算流程。

桌面周期列表显示状态、日期、范围、方案版本；详情为概览/制度/范围/结果/历史，手机页签可读，范围列表分页。删除只对无业务引用的配置草稿；已有事实周期归档展示而不物理删除。验收TERM-01合法转换、TERM-02非法匹配阻断、TERM-03复制不复制事实、TERM-04并发开启、TERM-05日期校验、TERM-06历史范围固定。
