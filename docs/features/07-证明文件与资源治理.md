# 证明文件与资源治理

日期2026-10-20；ENT-08；目标详细设计v1。现有文件签名、私有下载与hash可复用；隔离扫描及垃圾清理待实现。

证明为敏感业务资源，品牌资源独立存储。上传最大5MiB，PNG/JPEG/PDF真实签名，随机storageKey，服务端清理文件名，原名不组成路径。不接受SVG/HTML/任意远程URL；签名识别不是完整病毒扫描或内容可信证明。客户端显示上传进度/失败重试/已关联状态，不用假完成进度。

目标状态：UPLOADING→QUARANTINED→READY/REJECTED→RETIRED。只允许READY关联审核；扫描失败保持隔离，不对外开放。当前同步identify只建立基本格式校验，部署未配置扫描时必须在运维风险中如实记录，不能显示“安全检测通过”。数据库与磁盘无分布式事务，先临时文件→校验→写元数据→引用提交；失败补偿删除临时文件，定时重试核查孤立项。

下载每次验证会话和对象引用：管理员业务权限、上传者、该参与事实学生、该活动负责者；共享证明只因合法引用授权，不因知道id授权。attachment、nosniff、sandbox、no-store；hash不符报完整性错误并告警，不能返回损坏内容。无权私有对象目标统一404；日志不写正文/完整路径。已引用材料不自动删除，退回/撤销历史仍需保留。

清理先列无引用且超过保留期的候选→生成清单/hash→标记→重新检查所有引用→隔离移动→保留恢复期→最终删除。期限由组织核准，未核准仅清理明确上传中断临时文件，不删业务证明；不得递归清空附件目录。备份数据库与附件引用清单成对保存。

API现有POST /api/evidence与GET /api/evidence/{id}；目标GET /api/evidence/{id}/status及管理员清理预览/执行，客户端不能传storageKey。验收FILE-01格式/大小/数量、FILE-02中断补偿、FILE-03共享越权、FILE-04路径/文件名注入、FILE-05hash损坏、FILE-06清理引用竞态、FILE-07备份恢复后引用一致。
