# 身份与账号安全

日期2026-10-20；ENT-01；目标详细设计v1。当前认证/改密/初始化可复用，设备管理和完整安全运营尚未实现。

管理员由受控CLI一次初始化；已存在管理员时拒绝，不重置密码。账号由管理员创建，初始密码随机生成仅首次响应交付；必须首次改密。登录页只有账号、密码、错误反馈和联系管理员的业务提示，不开放注册和虚构找回邮件入口。改密页提供当前/新/确认密码，成功撤销所有会话并返回登录。

会话身份包含AuthSession id，服务端每次检查撤销、到期、User.disabled、authVersion、mustChangePassword；不把JWT中的旧role作为授权依据。8小时绝对会话到期为当前默认；如以后可配，变更只影响新会话，强制撤销为独立操作。本人可查看会话建立/到期时间并撤销其他会话，未知设备信息不伪造。密码12..72字符且UTF-8≤72字节，至少字母和数字，与旧值不同；bcrypt cost12，不记明文。

状态为INITIAL_PASSWORD→ACTIVE→DISABLED；重置回INITIAL_PASSWORD并提升authVersion。停用不是删除。并发改密以原hash+authVersion条件写入，只成功一次；重置/停用与敏感业务并发须在写入事务复查授权，失败不产生业务记录。登录按账号和受信边界限流，不能依赖不可信X-Forwarded-For。

API：现有NextAuth、POST /api/password、GET /api/admin/session；目标GET /api/sessions、DELETE /api/sessions/{id}。仅本人会话可撤销，管理员通过账号停用/重置撤销他人。错误登录统一文案；已登录会话失效401，首次改密业务写403。审计登录成功、改密、重置、撤销；不保存密码/cookie。登录失败计数HMAC，不保存用户密码输入。

桌面居中表单与克制品牌区域，手机单列表单；autocomplete=username/current-password/new-password，错误aria-live，提交期间锁定按钮可恢复；重定向仅同源路径。验收：AUTH-01双初始化、AUTH-02三角色与越权、AUTH-03旧cookie重放、AUTH-04并发改密/停用、AUTH-05限流、AUTH-06手机键盘及错误恢复。
