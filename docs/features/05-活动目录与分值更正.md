# 活动目录与分值更正

日期2026-10-20；ENT-06/05；目标详细设计v1。当前activities有维护/分值确认，已确认分值更正尚缺。

目录按周期、时间、关键词、确认状态筛选；列表进入独立详情，显示名称、组织者、内容、要求、开始结束、计分模块路径、分值/确认状态、本人来源状态。发布者管理自己负责的活动；学生只可向已确认且窗口内活动提交本人参与；管理员可维护并确认。发布者不能通过传ownerId改变归属。

新活动UNCONFIRMED→CONFIRMED。未确认可改分值和节点；已确认普通编辑只改描述/时间等非分数字段，保留审计。分值/节点更正必须提交新值+理由→服务器读取有效参与引用→预览人数/分差/受影响确认→固定候选→统一重算→短事务切换；过程复查activity.revision、term规则/输入/范围修订。不能先改Activity.points再异步慢慢更新可见结果。分值不得负数，节点须ACTIVITY叶，日期结束≥开始。

API现有GET /api/activities、POST action=save/confirm，目标GET /api/activities/{id}、POST /api/activities/{id}/change-preview、POST /api/activities/{id}/apply-change。详情读取服务必须复用列表的授权范围，不能靠前端传所有记录后过滤。CHECKING更正限管理员，LOCKED先重开；事务日志记录前后节点/分值、理由、preview/run和版本。

手机活动为时间、名称、组织者、分值和状态卡片，内容按段换行；主操作在正文后清晰可达，上传/提交进入单独步骤；长内容不挤压主操作。空态说明筛选或暂无活动。验收ACT-01归属越权、ACT-02非法节点/时间、ACT-03旧revision、ACT-04确认后不可绕过更正、ACT-05多来源分值只应用一次、ACT-06过期预览/重算失败保持原结果。
