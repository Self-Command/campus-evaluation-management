# 发布核对、确认与异议

日期2026-10-20；ENT-12；目标详细设计v1；当前尚未实现，不在页面宣称可用。

管理员发布面板先检查范围、全部必需成绩、待审和计算候选身份。仅允许完整且与当前规则/输入/范围修订一致的ResultSet发布，短事务设置publishedResultSetId并转CHECKING；不可发布半批。发布时间、操作者、规则/输入身份和通知去重写入同一事务。旧集state=SUPERSEDED保留可追溯。

学生查看固定结果后确认，提交resultSetId+resultHash；服务端只接受当前发布且本人结果，重复确认同一身份返回原确认。新结果发布后旧确认不会自动迁移，即使总分相同也需根据结果身份重新核对。页面明确显示本次是否已确认、确认时间，不用当前时间冒充已确认。

异议针对本人发布结果中的节点/事实/成绩/扣分/总分，理由2..2000字符，可附本人材料。OPEN→PROCESSING→RESOLVED/REJECTED；学生在未处理前可WITHDRAWN。管理员处理填写结论；认可需关联实际更正记录与新发布结果集，不能只写“已解决”而成绩未改；驳回须理由。结果变化后异议仍关联原集并能追踪resolvedResultSetId。

API目标POST /api/terms/{id}/publish、POST /api/results/{id}/confirm、GET/POST /api/appeals、PATCH /api/appeals/{id}。发布与确认幂等键持久化，异议修改带revision；并发发布/确认在周期锁内校验指针，旧确认409。截止时间由周期配置，过期仅管理员理由延长并审计，不默默接受。

手机确认前保留查看依据入口，按钮说明正在确认哪个周期版本；异议分目标选择、说明材料、提交；管理员处理是完整详情页。验收PUB-01不完整阻断、PUB-02输入变化冲突、PUB-03确认身份失效、PUB-04他人异议隔离、PUB-05更正关联、PUB-06重复请求、PUB-07发布/确认竞态。
