# 排名范围与安全导出

日期2026-10-20；ENT-13；目标详细设计v2。排名/CSV已有实现基础，学院班级限域及本人/班级公式详细成绩为新增待实施要求，当前事实见已核查接口。

最新导出目标以[统一审核规范](../product/学院职责与统一审核规范.md)第7节为准：辅导员导出授权班级全部学生，学院本院、学生本人；完整模块树的叶子原始分/原始扣分/规则参数为数值，小计、封顶、折算、比例和总分用XLSX公式。修改输入后自动重算，初始逐模块结果与同版本系统对账，缺录不当零。此公式详细成绩区别于既有排名CSV；下文旧数值列口径不用于把新详细成绩的派生列写死。

排名绑定已发布ResultSet与ScopeSnapshot，管理员选择全范围/学院/专业/班级的冻结成员集合。默认按最终两位displayTotal降序、同分竞赛名次1,1,3；学号仅稳定展示顺序，不拆同分。其他政策可选dense或ordinal但开启前确认，变更要新结果/发布身份。默认学生只见本人名次/参评人数，不开放同学个人明细；完整名单公开必须显式配置和隐私确认。

不完整成绩不参与正式排名，显示缺失原因与“无名次”，不能计0或排末尾制造正式名次。并列判据明确使用最终两位而非浏览器浮点/隐藏精度，导出和页面调用同一纯排名函数。跨方案可比性由组织制度确认；默认方案组内排名，跨方案组未确认可比时阻断合并。

导出选模板、字段和范围，生成前显示真实人数、结果集版本、生成目的；允许字段白名单，默认不带材料/密码/敏感联系方式。文本写明确文本类型；CSV对首个危险字符（含前导空白后的=+-@、tab/CR）进行公式注入防护并规范引号。系统分数写数值列，与文本学号分开。下载每次鉴权、no-store、审计范围/人数/hash，不在日志写整份名单。

API目标GET /api/rankings?resultSetId&scopeId&groupId&page、POST /api/exports、GET /api/exports/{id}、GET /api/exports/{id}/download。大导出作为有界后台任务，state=QUEUED/RUNNING/READY/FAILED/EXPIRED；失败重试不重复产生可见文件。临时导出有明确过期并重新鉴权，不能公开可猜URL。

手机默认姓名/学号/名次/总分卡片，筛选有文字，导出配置分步且可查看字段。验收RANK-01并列与负分、RANK-02缺失不排名、RANK-03范围冻结、RANK-04跨方案阻断、RANK-05公式注入、RANK-06页面导出同源、RANK-07下载越权/过期。
