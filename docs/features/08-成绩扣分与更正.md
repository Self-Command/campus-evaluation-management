# 成绩输入、扣分及更正

日期2026-10-20；ENT-09；目标详细设计v1。当前grades/deductions和审计基础可复用。

管理员选周期→学生→成绩模块，先查当前值与revision；表单显示规则范围、当前值、待保存值和理由。新建revision=null，已有必须携当前revision；同值不重复写。GRADE叶才接成绩，十进制字符串范围/精度写入前验证。空值不是0，必需缺失不完整，0是明确已录入。成绩覆盖不是追加求和。

扣分选制度项目，不接受客户端系数或节点。amount必须正数；实际扣减为amount×项目系数，在节点封顶/折算后、下限前。当前一周期一学生一项目一个当前值，修改覆盖，审计保留前后；若未来需要逐笔累计，应增加独立事实记录后汇总，不能改变当前值接口语义。撤销填写理由、保留amount/revision并设revoked，不物理删除；可有理由恢复有效。

ACTIVE允许普通写；CHECKING必须管理员更正并关联新结果集；LOCKED先理由重开。保存与inputRevision递增、审计同周期锁事务；并发旧revision409且原值不变。删除必需成绩目标走“标记缺失”操作与理由、预览影响，不用value=""写入Decimal。

API现有GET/POST /api/grades、GET/POST /api/deductions，GET termId+studentLogin返回输入；目标GET /api/input-history按实体/学生分页，POST /api/grades/{id}/mark-missing。审计记录节点/项目、前后值/撤销状态、理由、actor与输入修订，不将个人材料正文放details。

手机先选学生，再进入模块卡片单项编辑，长节点路径换行，当前与新值并排文本可读；更正弹窗底部可触达。验收INPUT-01缺失/0/负数政策、INPUT-02精度边界、INPUT-03同值幂等、INPUT-04并发覆盖、INPUT-05系数篡改、INPUT-06扣分顺序/撤销/重开、INPUT-07更正历史可复现。
