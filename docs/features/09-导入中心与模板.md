# 导入中心与版本模板

日期2026-10-20；ENT-10；目标详细设计v1。三类预览提交已实现，模板下载、统一交互和历史分页为目标。

最新目标优先采用[统一审核规范](../product/学院职责与统一审核规范.md)第6节：活动名单身份五字段严格核对、任一错误零写入、一活动一次正式导入且后续理由补录；证明在活动详情独立上传，不放名单列。下文login单列、重复SKIP及普通覆盖等为旧接口行为，不能据此实现新目标；成绩/扣分输入还需学院审核后生效，新能力待实施。

入口按账号、活动名单、成绩三类，角色决定可选类型。流程为下载模板/字段说明→选择文件→识别表头→映射→逐行差异→确认→结果。模板至少UTF-8 BOM CSV，学号示例为文本、明确前导零与XLSX文本列要求；账号必需login/name/college/major/className，名单login，成绩login/value。模板版本与解析规则关联，管理员只改展示说明/示例和有界别名，不能取消身份或业务必填校验。

当前支持1MiB、1..100数据行、最多30列、CSV UTF-8或单工作表XLSX；拒绝公式、宏、外链、压缩爆炸、日期学号和数字学号（不能恢复已丢前导零）。上传完整请求大小限制与解析解压限制分别执行。字段映射不能重复列，成绩学号与值不同列，列索引在实际表头范围内。

预览只建PREVIEW批次，不写账号/事实/成绩；rows状态及说明由服务端生成。账号NEW/SKIP/ERROR；名单NEW/EXISTING/SKIP/ERROR；成绩NEW/SAME/OVERWRITE/SKIP/ERROR，覆盖逐行展示before。任何ERROR整批阻断；完全重复行SKIP，不默默吞不同值。snapshot固定相关账号/活动/节点/输入修订，15分钟到期。

确认只认batchId并重新检查actor/阶段/归属/snapshot/到期；COMMITTED重试返回原结果replay=true，不再次写入或交付密码。账号hash在事务外准备，事务内再校验；初始密码仅首次响应，断网失去密码通过管理员重置单个账号，不从日志恢复。失败批次不部分落库；纠正文件后创建新预览而不修改旧批次。

API现有POST /api/admin/account-import、/api/participation-import、/api/grade-import；目标GET /api/import-templates/{kind}、GET /api/imports、GET /api/imports/{id}。列表仅本人批次，管理员是否看他人需要独立权限，默认不暴露凭据。每类模板下载权限与对应导入一致，不能用通用下载绕过role。

手机每次只展示一步，映射为一字段一行；预览卡片有行号/身份/变化/错误，支持只看错误和返回重传，提交前显示真实计数。验收IMP-01模板真实回导、IMP-02三类映射、IMP-03错误原子回滚、IMP-04并发提交、IMP-05过期/他人/旧snapshot、IMP-06数字学号/公式/zip限制、IMP-07一次性交付及手机闭环。
