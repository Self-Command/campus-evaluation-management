# 事实认定、个人申报与审核

日期2026-10-20；ENT-07/08/10；最新确认规范v2，待实施。以[学院职责与统一审核规范](../product/学院职责与统一审核规范.md)及ADR0005为准。当前代码仍有项目目录、可选活动关联和管理员单级审核，不能当作新流程已完成。

学生直接填写标题、发生日期、事实说明和本人证明。删除个人申报关联活动、事实键输入、可申报项目选择，以及管理员认定项目新建/编辑/启停和专用更正入口。无需其他人预建事项；辅导员初审时选择生效制度最底层计分模块并填写分数。学院只终审，学生接口拒收自报分数；退回不要求评分。旧项目/活动关联只作历史解释，不删除旧申报、证据或已发布结果。

个人申报为学生提交→责任辅导员评分初审→归属学院终审→有效计分。辅导员空分不能通过，合法零分区别未填写；评分和模块绑定申报修订。学院不能跳过辅导员，也不能直接改分。同一申请/事实不重复生效；活动事实仍保持(activityId,studentId)唯一，新个人申报不再依赖活动关联自动去重，疑似同事实由审核人员核实，不按相似标题自动合并。

所有普通申请退回必须有明确理由，交原发起人：学生申报退学生，辅导员成绩/扣分退辅导员，学院活动名单退主办学院经办人；纯个人申报评分问题内部退辅导员重评，学生不重交材料。申请人可修改重提或删除放弃；重提新修订重走必要审核，删除保留历史和材料引用，不删除有效事实。退回、重评、重提、放弃及并发规则详见统一规范第4、5节。

当前HTTP以[已核查接口](../api/已核查接口与兼容边界.md)为准。后续移除申报项目配置写接口，申报新建/重提不接受projectId/activityId/学生评分，审核接口实现身份、班级/学院、阶段、窗口和修订复核。批量使用明确ID及revision逐条检查，错误不部分提交；当前尚未实现的参数/路由不因本规范自动可用。有效审核变化与输入版本、审计在同事务处理。

页面保留指定完整模板的名录、详情侧栏/完整手机详情、材料预览和审核历史。学生新建表单无项目和活动选择；辅导员通过表单有计分模块/分数，学院有决定和理由。退回说明直达处理人；列表显示真实状态和真实操作。验收按统一规范REV-01～12，原有权限、证据所有权、去重、批量原子性和锁定断言继续保留，旧项目依赖断言按新需求替换为无需配置也可申报及旧配置写入被拒绝断言。
