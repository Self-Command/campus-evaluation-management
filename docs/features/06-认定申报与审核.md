# 事实认定、个人申报与审核

日期2026-10-20；ENT-07/08/10；目标详细设计v1。当前活动单人/批量来源及管理员审核可用基础；个人项目、补充/撤回及批量审核为目标。

活动参与以(activityId,studentId)唯一。来源可来自学生本人或活动组织；同一事实任意一份有效通过来源即可计一次，多份证明或来源均不倍增。学生选择活动、说明、1..5份本人材料提交；发布者仅对本人活动选学生/导名单；管理员审核不得以提交者自报分值计算。来源列表展示本人可见对象、状态、理由、附件和历史。

PENDING→APPROVED/REJECTED/NEEDS_CHANGES，PENDING本人可WITHDRAWN；NEEDS_CHANGES本人补充后重新PENDING且revision递增，旧材料与ReviewEvent保留。APPROVED撤销以管理员理由与结果影响更正，不物理删除。批量审核最多100个明确ID+各revision+共同理由，任一无权/冲突整批失败，返回可定位阻断；不能对“当前筛选全部”未固定集合盲改。管理员默认最终审核，审核分级不自行扩张。

个人项目由管理员维护项目/规则版本/ACTIVITY节点/固定分值；学生填写事实键、发生日期、说明和材料，不能自定分值。项目同学生同factKey唯一；存在活动同事实时提示管理员关联/合并，必须说明采用与撤销来源，不能靠文件hash合并。有效个人事实与活动事实统一进入计算输入依据。

API现有POST /api/activities action=submit/review、GET view=reviews；目标GET/POST /api/projects、GET/POST /api/claims、POST /api/claims/{id}/submit、POST /api/claims/{id}/withdraw、POST /api/reviews/batch。所有写入周期锁、身份/归属/窗口复查、对象revision；提交成功不等于计分，审核有效性改变递增inputRevision并使候选过期。更正产生的通知与业务同事务去重，不以通知成功代替审核提交。

桌面审核列表→详情侧栏显示事实/证明/历史→决策表单；手机完整详情页，文件下载不嵌不安全预览，决策有理由与确认。验收REC-01跨学生/跨发布者隔离、REC-02来源去重、REC-03补材料历史、REC-04不能自定分、REC-05批量原子性、REC-06撤销/锁定竞态、REC-07重复事实人工合并追溯。
