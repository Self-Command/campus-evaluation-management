# 导出表头与成绩导出重构

日期：2026-10-22。本轮按用户提供的成绩明细表样式，重做班级/学院/全校成绩明细导出表头，并统一学生成绩单的用户用语。只记录实际修改与命令检查，不把构建通过或文件可打开当作浏览器、Excel/WPS 人工验收。

## 一、用户看到的变化

- 表头按评分方案的模块树自动分层合并：大模块包含子模块，子模块再包含得分项，不再把整棵树压成一行长表头。
- 模块名称直接作为分组表头；父级占比写成 `×80%`、`×10%`，分数上限写成“不超过100分”，换算写成“100分换算为20分”。
- 叶子得分列只写“得分”，不再出现“原始分”“原始输入”。
- 内部模块显示“实际分合计”，有上级占比时显示“比例分”；每一级汇总都能直接看出来。
- 扣分、扣分合计、录入情况、综合测评总分、学生本人签字确认集中放在末尾分组。
- “缺录”和明确零分仍分开显示：必填项为空时总分显示“缺录”，填写 0 时按 0 计分。
- 学生个人成绩单同步改为“得分、小计、上限后、换算后、模块得分”等用户语言，去掉导出中的“原始分、原始扣分、封顶、计入分”等内部阶段名。
- 评分规则页仍保留可修改参数，黄色单元格可填写，灰色单元格自动计算。

## 二、实现位置

- `src/lib/xlsx/class-sheet.ts`：按模块树递归生成列、合并表头、实际分/比例分列和公式；保留缺录校验、扣分、上限、换算与最低分规则。
- `src/lib/xlsx/grade-model.ts`：个人成绩单列名与说明改为用户语言，公式与评分引擎继续同源。
- `src/app/(workspace)/grades/_components/grade-export-dialog.tsx`：导出说明同步为“得分、扣分和规则参数”。
- `tests/integration/class-sheet.test.ts`：新增多级模块嵌套、表头层级、合并区域、比例分公式和“无原始分术语”测试。
- `tests/integration/grade-model.test.ts`：个人成绩单公式测试随新表头复核。

## 五、全部导出统一重构与视觉验证（同日最终状态）

用户确认按方案实施，要求所有导出统一修复，并且评分配置变化后表头与版式仍能自适应。本节记录最终实现与验证，覆盖第四节的旧结论。

### 1. 覆盖范围

- 全校、学院、辅导员、班级成绩明细（同一构建器与同一主题）。
- 学生个人成绩单。
- 排名表：由 CSV 改为带样式的 XLSX，原导出入口同步更名。

### 2. 自适应实现

- 表头由 `validateScheme` 返回的真实模块树递归生成。任意层级数、模块数、顶层占比、上限、换算、最低分、扣分项目以及“根节点本身就是输入项”均能生成完整表头，不按模块名称或固定列号写死。
- 列顺序、合并区域、每级实际分合计/比例分、个人成绩单的上限后/换算后/扣分后各阶段都由树结构决定。
- 颜色按顶层模块顺序从 8 组色带循环选取；新增、删除、重命名或调整模块顺序不会破坏配色。
- 无分单元格统一写 0，不再出现空白的得分格。

### 3. 版式与打印

- 大标题合并、元信息行、双层/多层分组表头、扣分块、结果与签字块；整表粗外边线、模块中等分隔线、单元格完整细边框。
- 冻结标题/表头与固定信息列；打印横向、按列数自适应 A3/A4、宽度缩放到一页、重复标题行与固定列、限定打印区域、页脚页码。
- 实时导出保留公式和“评分规则/参数”工作表；正式发布快照为只读数值，无公式、无规则表，避免官方快照被修改。

### 4. 视觉检查发现并修复

- 个人成绩单扣分说明在窄列内被裁剪：扣分表头及每行说明合并 `F:I` 并加宽。
- 排名表前三名名次被总分样式带成 `1.00 / 2.00`：新增整数名次样式。
- 导出中的发布时间、导出时间和文件名此前按 UTC 生成，比本地时间早 8 小时并可能跨日：统一改为本地时间格式，发布快照日期标签和三类文件名同步修正。
- 发布快照不再包含规则表后，导出对话框仍宣称“两张表”和“规则参数在最后一页”：按实时/发布两种状态分别显示说明，发布状态明确为只读快照。

## 六、全角色统一明细表（同日最终纠正）

用户指出：学院、管理员排名、学生个人等所有导出的表头应当一致，都是详细成绩；导出范围只由角色决定；所有文件按学院、专业、班级连续排序。本节覆盖第五节中“个人成绩单保留纵向阶段表”“排名表为独立简表”的旧实现。

### 1. 统一口径

- 全校、学院、辅导员、班级、学生个人、管理员排名导出全部调用 `buildClassSheet`，共用同一套固定列、模块树表头、扣分块、结果与签字块、主题色和打印设置。
- 固定列统一为：序号、姓名、学号、学院、专业、班级。学生个人导出也保留学院、专业、班级，不再因范围小隐藏组织列。
- 行顺序在构建器内统一排序：学院 → 专业 → 班级 → 学号 → 姓名 → 登录名，不依赖数据库返回顺序。
- 管理员排名页的导出不再输出“名次 + 综合成绩”简表，也不受页面筛选影响；固定导出全校明细。名次仍在排名页面查看。
- 排名页可查看历史发布版本；导出按当前查看的发布版本生成，使用该版本冻结的组织字段、方案与成绩，不会误导出最新版本。
- 学生个人导出由纵向“得分/小计/上限后/换算后”成绩单改为同一张横向明细表，只保留本人一行。
- 删除不再使用的 `grade-model`、`grade-layout` 及其测试，移除仅供旧排名简表使用的整数名次样式，避免两套导出继续分叉。

### 2. 涉及入口

- `src/lib/xlsx/class-sheet.ts`：统一排序与同一构建器。
- `src/server/class-grade-export.ts`：学院/辅导员/全校始终输出组织列。
- `src/server/grade-export.ts`：学生个人改为一行明细。
- `src/server/rankings.ts`：新增 `exportRankingGradeWorkbook`，按所选发布版本冻结数据生成全校明细并记录审计。
- `src/app/api/rankings/export/route.ts`：接收 `publicationId` 并调用排名明细导出。
- `src/app/(workspace)/rankings/_components/rankings.tsx`、`rankings/page.tsx`：入口与文案改为“导出全校成绩明细表”，链接携带当前发布版本。
- `src/app/(workspace)/results/_components/result-view.tsx`：学生入口改为“导出成绩明细表”。
- `src/app/(workspace)/grades/_components/grade-export-dialog.tsx`：说明补充分组排序规则。
