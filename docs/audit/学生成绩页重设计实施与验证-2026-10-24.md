# 学生成绩页重设计实施与验证（2026-10-24）

## 需求与交付

用户指出原学生“我的成绩”页“太杂、用户体验差、出现裸链接”，要求先重新设计再由用户验收。获批方案见[学生成绩页重设计](../design/学生成绩页重设计-2026-10-24.md)。本轮按该方案完成 `/results` 学生本人视图；管理员查询单个学生时沿用同一结构，保留查询、返回学生名单和导出入口。

页面改为单页滚动、结论优先、按需展开，不再使用页签：

| 区块 | 本轮结果 |
| --- | --- |
| 成绩概览 | 总分只出现一次；最终性徽标；班级排名、成绩状态、确认状态、核对截止四项指标；按身份和周期阶段生成确认、异议、查看依据、导出、成绩说明操作；未录完时显示缺项警告 |
| 得分构成 | 一个分隔列表；隐藏总成绩根节点；顶级模块展开、更深层级折叠；整枝零分合并为“未得分项”；桌面右侧粘性说明卡，移动端选中行下就地说明 |
| 计分依据 | 活动与成果、成绩录入、扣分三组；每行一个“查看”；详情对话框展示材料、扣分事由和变更历史 |
| 成绩说明 | 版本对话框承载方案版次、更新次数、发布批次、核对期限、确认情况和职责说明 |

裸链接、`factKey`、记录 ID 和接口字段不再出现在页面。需要跳转时使用带文字的按钮。

## 排名口径

原页面把“名次/人数”写成全校范围。本轮改为**班级内排名**：

- `getStudentResult` 读取已发布快照时按 `publicationId + className` 取同班记录，再用原有并列名次算法计算。
- 页面指标标注“班级排名”和“本班本次发布”，未发布时显示“发布后可查”。
- 名次只来自已发布快照，不读取当前输入或临时计算结果。
