# 学生活动入口合并实施与验证

日期：2026-10-22。范围：按[角色视角UI规范与页面改造分析](角色视角UI规范与页面改造分析-2026-10-22.md) 4.1 与 P1 第 2 项，把学生侧三个活动入口合并为一个页面。本文只记录本轮实际改动与命令行证据，不代替用户浏览器验收。

## 1. 改动前的问题

学生侧栏同时存在「我的活动」`/activities`、「学校发布的活动」`/activity-feed`、「活动参与记录」`/recognitions` 三个入口：

- 「我的活动」与「活动参与记录」对学生的数据源几乎相同（都是本人已登记的参与），只是列不同，学生无法判断该点哪个；
- 「学校发布的活动」是浏览入口，却与「我的活动」平级，容易被误解成需要报名；
- 三个页面各自重复一遍页头说明，违反“任一页面只有一个标题和一段说明”。

## 2. 实施结果

| 文件 | 改动 |
| --- | --- |
| `src/app/(workspace)/my-activities/page.tsx` | 新增。学生专用活动页，`view=joined`（默认，我参加的活动）与 `view=feed`（面向我发布的活动）两个视图；页头一处标题与说明，视图切换为链接（保留 `termId`，切换重置搜索与分页）；非学生访问重定向到 `/activities` |
| `src/app/(workspace)/my-activities/_components/student-activity-feed.tsx` | 新增。面向学生发布的活动卡片网格，含搜索、分页、空态与“活动怎么参加”说明卡；只渲染真实已发布活动 |
| `src/app/(workspace)/activities/page.tsx` | 学生访问时重定向到 `/my-activities`（保留 `termId`、`q`、`page`）；删除已不可达的学生文案分支 |
| `src/app/(workspace)/activity-feed/page.tsx` | 收敛为深链兼容入口：学生重定向到 `/my-activities?view=feed`，其他角色仍去 `/activities` |
| `src/app/(workspace)/recognitions/page.tsx` | 学生访问时重定向到 `/my-activities`；删除已不可达的学生标题/说明分支，其他角色不变 |
| `src/app/(workspace)/activities/_components/activity-list.tsx` | 学生列表标题改为“我参加的活动”；「审核进度」列在状态徽章下补「退回原因」，避免合并后丢失退回说明 |
| `src/app/(workspace)/_components/student-workbench.tsx` | “待补材料与申报进度”入口改为 `/my-activities`，“近期活动”入口改为 `/my-activities?view=feed`，按钮名与页面一致 |
| `src/navigation/sidebar/sidebar-items.ts` | 学生“测评业务”只保留一个“活动”入口；管理员、学院、辅导员侧栏不变 |
| `scripts/test-http.ts` | 学生 HTTP 路径改为 `/my-activities` 与 `/my-activities?view=feed`，并补一条学生合并页检查 |

## 3. 验证证据

- `npx tsc --noEmit` 通过（0 错误）。
- 目标文件 `npx eslint … --max-warnings=0` 通过。
- 本机开发服务 HTTP 检查（未操作浏览器）：
  - 学生登录后 `/my-activities` 200，含“我参加的活动”“审核进度”；
  - `/my-activities?view=feed` 200，含“面向你发布的活动”“活动怎么参加”；
  - `/activities`、`/recognitions`、`/activity-feed` 均重定向到合并页（`/activity-feed` 指向 `?view=feed`）；
  - 学生首页侧栏只剩一个 `/my-activities` 入口，不再出现 `/activities`、`/activity-feed`、`/recognitions`；
  - 管理员登录后 `/my-activities` 重定向到 `/activities`，侧栏仍是 `/activities` 与 `/recognitions`。
- 未运行 `npm run build`（上一轮构建由用户主动取消，本轮不重跑）；实际水合、断点与视觉由用户验收。

## 4. 取舍与遗留

- 学生不再单独进入 `/recognitions`：该页对学生只读，信息与「我参加的活动」重复；退回原因已并入列表列，证明与历史仍可在活动详情查看。
- 三个旧路径保留重定向，已有深链、工作台入口和导入向导里的链接不会 404。
- 第二轮仍未完成：成绩、扣分页按角色分栏；活动详情右侧操作区“一个主下一步 + 更多操作”；全站重复 `PageHeading` 与列表标题。
- 第三轮（学生成绩页重排、周期状态列、结果发布步骤条、导入向导措辞）未开始。
