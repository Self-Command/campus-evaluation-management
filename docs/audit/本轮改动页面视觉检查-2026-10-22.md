# 本轮改动页面视觉检查与修正

日期：2026-10-22。范围：本轮（角色工作台、学生活动合并、成绩/扣分分栏、活动详情操作区、列表标题去重）实际改动或新增的页面。方法：本机开发服务 + Playwright 无头 Chromium 截图（1440×900 桌面、390×844 移动），使用真实账号与真实数据；截图存于 `.local/visual/`（已忽略，不提交）。本文记录看到的问题和据此做的修正，最终视觉验收仍由用户在浏览器完成。

## 1. 检查范围

| 角色 | 页面 |
| --- | --- |
| 学生 | `/`、`/my-activities`（我参加的活动）、`/my-activities?view=feed` |
| 辅导员 | `/`、`/grades`、`/deductions` |
| 学院 | `/`、`/grades`、`/deductions` |
| 管理员 | `/activities/[id]` 活动详情 |

移动端另外检查 `/my-activities` 两个视图与 `/grades`，并读取 `documentElement.scrollWidth - clientWidth` 判断横向溢出，三页均为 0。

## 2. 发现的问题与修正

| # | 问题 | 判断依据 | 修正 |
| --- | --- | --- | --- |
| 1 | 全站 `outline` 按钮没有可见边框，搜索、查看活动、上一页等操作看起来像纯文字 | 计算样式显示 `border-color: rgba(0,0,0,0)`；`border-border` 与基础类 `border-transparent` 同时存在，样式表中透明色规则后置生效 | `src/components/ui/button.tsx`：基础类去掉 `border-transparent`，改由各变体自行声明；`outline` 保留 `border-border`，其余变体补 `border-transparent`。修正后实测边框为 `lab(90.95 0 0)`（约 #e5e5e5） |
| 2 | `/my-activities` 的两个视图切换只有两个纯文字链接，看不出是可切换的分栏 | 桌面与移动截图 | 改为分段控件：外框 `rounded-lg border bg-muted/40`，选中项白底 + 阴影，未选中灰色文字；保留 `aria-current` |
| 3 | 列表卡片标题删除后，工具栏左侧空白，只剩右侧搜索框 | 桌面截图 | `TemplateDirectory` 的 `title` 改为可选；被删标题的列表改用短计数说明（“共 N 个活动 / 共 N 条成绩修改 / 共 N 条扣分记录 / 共 N 位学生”），工具栏左计数、右搜索与操作 |
| 4 | 学生活动卡片在 9 栏宽度里排三列，每张约 250px，内容挤压 | 桌面截图（1 项时看不明显，按 3 项推算） | 卡片网格改为最多两列 `sm:grid-cols-2` |
| 5 | 移动端成绩/扣分页三张统计卡竖排，首屏被统计占满，看不到当前栏与学生列表 | 390px 截图 | 统计卡改为 `grid-cols-3` 单行、间距缩小、数值 `text-xl sm:text-2xl`，标签 `text-xs`；桌面恢复原字号 |
| 6 | 页面标题与列表标题重复（`成绩录入` / `负责班级成绩` 等） | 桌面截图 | 本轮改动的页面已去掉列表重复标题，只保留页头一处；`TemplateDirectory` 支持不传标题 |

- 第 1 项是组件级修正，会影响所有使用 `outline` 按钮的页面（外观变清晰，布局不变：仍为 1px 边框）。这是本轮唯一超出“改动页面”范围的修改，已在下方风险中说明。

## 3. 修正后的复核

- 重新截图确认：`/my-activities` 两视图的分段控件、计数与搜索分列左右；成绩页统计卡在移动端单行显示；活动详情页标题区只剩“周期阶段 + 当前状态”两个徽章，主办学院为次要文字。
- 移动端三页横向溢出均为 0。
- `npx tsc --noEmit` 通过；`npm run lint` 全量 0 问题。
