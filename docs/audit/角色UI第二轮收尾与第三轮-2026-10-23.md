检查中发现并已修正的问题：

1. 步骤条最初使用 `sm:grid-cols-4`，在 1440px 下仍只有一列；计算样式确认网格模板未生效，改为 `grid-cols-2 xl:grid-cols-4`，桌面四列、移动两列均已复测。
2. 多个列表的 PageHeading 与 Card 标题重复；统一删除 Card 标题后，工具栏左侧由计数说明补位，搜索与主操作仍在右侧。
3. `TemplateDirectory` 说明在宽容器中换行过长，限制最大宽度并收紧行高。
4. 版本折叠触发器最初展开后箭头不旋转：Base UI 把 `data-panel-open` 放在触发器自身，而旋转类依赖外层的 `group`。给触发器补 `group` 后复测计算样式为 `rotate: 180deg`，展开内容与折叠状态一致。

最新截图脚本未记录到页面错误或 404；接口数据为本地真实开发库，截图中的姓名与成绩不写入文档。
