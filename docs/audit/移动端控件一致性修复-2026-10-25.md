# 移动端按钮高矮与宽窄不一致分析与修复

日期：2026-10-25

状态：已修复，随 v0.3.7 发布。

范围：390px 手机宽度下的操作按钮、图标按钮、标签页、开关组、选择器、侧栏菜单和输入组合框。

## 结论

问题不是某一个页面的样式，而是移动端触控规则只覆盖了部分 `data-slot`，且仅约束高度、没有约束宽度：

- `src/app/globals.css` 原先只对 `[data-slot="button"]`、`[data-slot="sidebar-menu-button"]`、`[data-slot="select-trigger"]` 设置 `min-height: 44px`。
- Base UI 的弹层触发器会渲染为 `popover-trigger`、`dialog-trigger` 等不同槽位；标签页是 `tabs-trigger`，开关组是 `toggle-group-item`，侧栏开关是 `sidebar-trigger`，输入组合框内部按钮也带不同类名。这些控件没有被规则命中。
- 被命中的图标按钮只得到 44px 高度，宽度仍是 32px 或 28px，于是同一行里出现“又高又窄”的胶囊/方块。
- 标签页和原生按钮链接（`buttonVariants` 用于 `<a>`/`Link`）不经过 `data-slot="button"`，完全保持 25–36px 高。

修复前的自动测量示例：

| 页面 | 控件高度分布 | 典型问题 |
| --- | --- | --- |
| `/grades` | 25、28、32、44 | 两个标签页 25px；侧栏开关 28px；顶栏弹层与导出按钮 32px |
| `/settings` | 25、28、32、44 | 五个设置标签页 25px；顶栏图标 28/32px；内容输入框 44px |
| 全站顶栏 | 28、44、32 | 同一行的侧栏开关、外观按钮、主题按钮三种尺寸 |

## 修复方案

统一在共享组件层解决，不逐页补丁，桌面尺寸保持不变。

### 共享控件

| 文件 | 修改 |
| --- | --- |
| `src/components/ui/button.tsx` | 基础类增加 `max-md:min-h-11 max-md:min-w-11`，所有按钮（含 `buttonVariants` 链接、Base UI `render` 触发器）在小于 768px 时至少 44×44；`xs`/`sm` 在手机端文字提升到 14px |
| `src/components/ui/select.tsx` | `SelectTrigger` 增加 `max-md:min-h-11` |
| `src/components/ui/toggle.tsx` | 基础类增加 `max-md:min-h-11 max-md:min-w-11`；`sm` 手机端文字 14px |
| `src/components/ui/tabs.tsx` | `TabsTrigger` 增加 `max-md:min-h-11 max-md:min-w-min max-md:px-2.5`，保证标签不被压缩到文字重叠，短标签仍达到 44px 宽 |
| `src/components/ui/sidebar.tsx` | `SidebarMenuButton`、`SidebarMenuSubButton` 手机端最小高度 44px；`sm` 菜单文字 14px |
| `src/app/globals.css` | 标签栏手机端高度自适应、内边距 2px、默认分段标签间距 2px；输入组合框外层自适应到 44px，附加区去掉上下内边距；移除原先只覆盖三个槽位的高度规则 |
| `src/components/dashboard/searchable-select.tsx`、`searchable-multi-select.tsx` | 搜索结果行手机端最小高度 44px |

### 为什么标签页要单独处理

`TabsList` 水平方向原本固定 `h-8`，`TabsTrigger` 只有 25px。仅给触发器加高度会让内容溢出固定高度的容器。因此手机端让容器高度自适应，并把内边距降为 2px；触发器最小高度 44px。设置页五个标签会按可用宽度换行成两行，每行均分宽度，文字不再挤在一起。

### 未采用的做法

- **全站统一改高桌面控件**：会破坏模板的紧凑桌面密度，本次只在 `<768px` 生效。
- **逐页添加内联样式**：触发器槽位分散，新增页面仍会遗漏。
- **强制所有标签页横向滚动**：多标签页面在手机上更难发现后续选项，现有页面已支持换行，保留换行。

## 边界

- 只修改共享控件类名和手机端 CSS，未改业务逻辑、接口、数据、权限、审计和页面结构。
- 桌面端、平板横屏（≥768px）保持原有模板密度。
