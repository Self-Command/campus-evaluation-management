## 6. 复检发现并修复

| 缺陷 | 根因 | 修复 | 回归 |
| --- | --- | --- | --- |
| 备份文件名重复 | 30 字符截断丢弃时间与唯一后缀 | 文件名含备份 ID、保留 `.dump`、140 字符截断 | 连续创建/上传备份均唯一 |
| 上传 16 MB 备份返回大小不一致 | Next.js 代理默认 10 MB 缓冲截断请求体 | 8 MiB 分块 + 偏移续写；代理上限 64 MB | 上传、预检、中止全部通过 |

| 活动证明上传事务失败 | 审计动作名 `ACTIVITY_EVIDENCE_UPLOADED` 未登记 | 统一为 `ACTIVITY_EVIDENCE_ADDED`；入参改为 `AuditAction` 类型 | 33 文件/152 项通过 |
| 交换后崩溃可能永久维护或误解除保护 | 维护门禁跳过启动对账；终态未区分回滚失败 | 对账放行并区分交换前后/终态；仅 `RESTORE_ROLLBACK_FAILED` 保留维护 | 新增 3 项对账测试，全部通过 |
| 最终 lint 门禁 2 个错误 | effect 内同步置状态、渲染期写 ref、未使用符号 | 加载态改为派生值；轮询依赖稳定 `reload`；清理未使用代码 | `npm run lint` 0 错误 |

## 7. 遗留与边界

- 浏览器视觉与交互验收由用户执行；agent 未操作浏览器进行验收。
- 数据库备份不含证明与活动附件文件；恢复只检查缺失/孤儿风险，不执行文件回写。
- 生产恢复未在服务器执行；发布后如需桌面演练，应在服务器临时库/临时容器进行，不动生产库。
- 服务器 Nginx 需允许至少 70m 请求体，才能上传接近 50 MB 的活动附件；备份上传按 8 MiB 分块，不受单请求大小累积影响。
- 发布使用 GitHub Actions 构建镜像、固定标签、仅重建应用容器；服务器数据库、卷、端口和其他项目不受影响。`0.3.0` 镜像已构建但未部署，实际随 `0.3.1`（登录背景回退修复）发布，见[登录背景回退与品牌资源缓存修复](../audit/登录背景回退与品牌资源缓存修复-2026-10-25.md)。
