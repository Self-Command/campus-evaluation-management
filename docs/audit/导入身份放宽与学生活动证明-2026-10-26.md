# 导入身份放宽与学生活动证明实施记录（2026-10-26）

版本：`0.4.0`  
设计依据：[导入身份校验放宽与学生活动证明查看设计](../design/导入身份校验放宽设计-2026-10-26.md)  
范围：活动参与名单导入、成绩导入、学生只读查看活动证明；学生账号导入保持严格校验

## 1. 实施结果

### 1.1 导入身份匹配

- 参与名单与成绩导入改为按“学号 + 姓名”识别学生；学号使用 NFKC、去零宽、去首尾空白和大小写规范化，姓名额外去除空白。
- 学号查询使用规范化变体兼容全角数字、大小写和零宽字符；同一学号匹配多个账号时整批阻断，提示先处置重复账号。
- 姓名不一致仍为错误并阻断整批，提示“学号与姓名不一致，请核对后重新导出模板”。
- 学院、专业、班级列改为可选参考：缺失或留空不提示；与系统档案不一致时生成逐行提示，按系统档案匹配、归属和授权，不阻断导入。
- 账号导入仍要求学号、姓名、学院、专业、班级完整匹配，不放宽。

### 1.2 模板与页面

- 参与名单默认模板升级为 `participation-v6`（学号、姓名）；成绩默认模板升级为 `grades-v4`（学号、姓名、成绩）。
- 旧五列/六列文件继续兼容：服务端按表头识别必需列，多余组织列可读取、可忽略。
- 导入向导新增“组织提示”页签、逐行黄色提示、提示总数和“确认导入（含 N 条组织提示）”按钮文案；结果摘要保留提示数。
- 预览卡片增加始终可见的组织提示摘要，避免宽表横向滚动把警告正文藏在屏幕外；说明列设置最小宽度，修复逐字竖排。
- 导入页说明明确“学号 + 姓名匹配，学院、专业、班级可留空，以系统档案为准”。

### 1.3 学生活动证明

- 已登记参加且参与未移除的学生，在活动详情显示只读“活动证明”页签，可预览和下载当前有效版本。
- 页面不显示上传、更换、删除和历史版本；学生文案说明证明由主办学院上传。
- 未登记、已移除参与的学生不显示页签；服务端 `getActivity` 不返回证明元数据。
- `downloadEvidence` 对学生活动证明同时校验有效参与和 `active=true`，历史版本、未登记和已移除学生拒绝；个人材料、申报和异议的原授权不变。
- 活动撤回后，只要参与有效，学生仍可查看证明（与设计建议一致）。
- 主办学院上传对话框增加“该说明会展示给参加活动的学生，请勿填写内部备注”。
- 删除未使用的 `canReadActivityEvidence`，避免权限口径分叉。
