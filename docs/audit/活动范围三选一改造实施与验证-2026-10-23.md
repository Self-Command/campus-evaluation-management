# 活动范围三选一改造实施与验证（2026-10-23）

## 需求与决策

用户质疑“发布活动是否必须同时命中所有范围选项”，并要求重新设计。最终采用单一范围方式：

- 先选择 `全校`、`按学院`、`按班级` 中的一种，不再叠加多个维度。
- 同一方式内多选取并集；不同方式之间不组合。
- 默认 `按学院`；学院账号只维护一个学院时自动预选本院。
- 草稿允许暂时不选，发布时当前方式必须至少有一项，且实际匹配到至少一名有效学生。
- 范围只决定学生能否在活动列表看到活动，不改变“参与名单由主办方导入或维护”的既有规则，也不提供学生自行报名。

此前“学院/专业/班级/学生”四组条件叠加的方式已删除；旧数据按迁移规则归入最接近的单一方式。

## 数据与迁移

- `prisma/schema.prisma` 新增 `ActivityAudienceScope`（`ALL | COLLEGE | CLASS`）与 `Activity.audienceScope`，默认 `COLLEGE`；保留 `audienceColleges String[]`、`audienceClasses String[]` 作为当前方式的名单。
- 迁移 `prisma/migrations/20261023170000_activity_audience_scope/migration.sql`：
  - 创建枚举并添加字段。
  - 旧记录中存在班级集合的改为 `CLASS`，并清空学院数组。
  - 其余记录保持 `COLLEGE`，并清空班级数组。
- 未使用的数组在保存时清空，避免切换方式后旧名单继续参与匹配或出现在详情中。

## 服务端规则

`src/server/activity-policy.ts` 集中范围逻辑：

- `audienceSchema` 只接受当前方式对应的数组；`normalizeAudience` 统一整理输入。
- `activityAudience` / `audienceFields` 负责读写 `audienceScope` 与两套数组。
- `inActivityAudience` / `studentEligibleWhere` 按 `ALL`、`COLLEGE`、`CLASS` 分别匹配；学院和班级都在同一方式内取并集。
- `inspectAudience` 按当前方式校验空选、学院或班级已无有效学生、零匹配；零匹配提示只在没有选择错误时追加，避免同时出现两条互相掩盖的提示。
- 预览只返回人数与学院/专业/班级汇总，不返回学生姓名或学号。

`src/server/activities.ts`：

- 活动列表与详情按 `audienceScope` 判断学生、辅导员、学院可见性；班级方式的名单键包含学院、专业、班级，避免同名班级跨院误匹配。
- 修复搜索 `OR` 与范围资格 `OR` 互相覆盖的问题：搜索条件与范围条件统一放入 `AND` 数组，任一条件都不会丢失。
- `participation-import.ts` 的名单快照补充 `audienceScope`，与学院/班级集合一起保留发布时范围。

## 页面与文案

- `audience-editor.tsx`：范围方式切换使用 Base UI `ToggleGroup`；`全校` 显示说明卡，`按学院` 只显示学院多选，`按班级` 只显示班级多选。切换方式保留另一方式已选内容以便切回，但不提交、不参与预览。
- `activity-form.tsx`：默认范围按角色初始化；右侧摘要显示“范围方式 + 已选数量”；预览与保存只提交当前方式。
- `activity-detail.tsx`：发布范围显示范围方式，发布确认按当前方式展示人数与学院/专业/班级汇总。
- 学生活动文案明确“范围内可见、名单由主办方维护”，删除“可看到并报名”这类与规则冲突的表述。
- 本批没有新增布局或视觉体系，模板来源与适配边界记录于 `docs/design/模板来源与适配清单.md` 的“活动范围三选一与页签滚动条（2026-10-23）”。

## 活动详情页签滚动条

用户指出活动详情页签右侧/底部出现多余滚动条。定位结果：

- 页签外层为横向滚动容器，`overflow-x: auto` 会使计算后的 `overflow-y` 也为 `auto`；页签选中下划线带来 1 像素纵向溢出，浏览器因此显示竖向滚动条。
- 外层此前已写 `scrollbar-none`，但 `src/app/globals.css` 没有定义该工具类，类名实际无效。

修复：

- 在 `src/app/globals.css` 增加 Tailwind v4 `@utility scrollbar-none`：`scrollbar-width: none` 加 `::-webkit-scrollbar { display: none }`。
- 活动详情页签外层使用 `scrollbar-none touch-pan-x overflow-x-auto overscroll-x-contain border-y`，隐藏滚动条，同时保留横向触摸与滚轮滚动。
- 账号、个人资料、成绩工作台的页签外层此前也使用了同一类名，补上定义后一并生效，不再出现同类多余滚动条。

## 测试

- `tests/integration/activities.test.ts` 新增“范围方式三选一并集匹配，切换方式清理未使用名单，空范围不可发布”：
  - 全校方式统计全部有效学生，并校验学院/专业/班级聚合数量。
  - 学院与班级方式按并集匹配，切换方式后未使用数组被清理。
  - 空选与零匹配被发布校验拦截。
- `tests/integration/flow-repairs.test.ts`、`import-role-matrix.test.ts` 更新为 `audienceScope` + 单方式名单；班级并集用例保留。
- `scripts/seed-acceptance.ts`、`scripts/test-http.ts`、e2e 夹具同步范围字段，避免旧形态直接写入数据库。
- `tests/e2e/my-activities.spec.ts` 截图显式使用 `caret: "initial"`，避免 Playwright 默认隐藏光标时注入内联样式与 React 水合竞争，造成假的水合错误。
- `tests/e2e/quick-scheme.spec.ts` 的保存断言改为全局“评分方案已保存”提示，因为行内提示会随 `router.refresh` 重挂载清空。
