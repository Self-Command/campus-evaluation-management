# 目标字段字典与约束

日期：2026-10-20。状态：目标契约 v1，表尚未据此全部创建；当前16表见[数据模型](数据模型.md)。关联 ENT-02～16。下列设计保留当前表与字段，经增量迁移落地。

## 共同约定

id 为应用 cuid text 主键，无业务排序含义；所有新时间字段用 timestamptz(3)，API UTC ISO8601。现有 timestamp 字段在确认历史时区前保持不变。`?`可空；其余非空；`revision:int=0`为乐观并发版本，`createdAt:time=now`，actorId/studentId 均 FK User.id RESTRICT。新表禁止业务级联删除。状态以数据库 enum/check 限制；JSON 由版本化 Zod schema 校验，不能作为万能扩展字段。分数沿用 Decimal(22,12)，有理数存 `{numerator,denominator}` 字符串；displayTotal 为最终half-up两位，精确总分单独保存。

## 迁移门禁

先运行只读孤立引用检查，输出匿名计数及单独受控修复清单。新增表/可空字段→兼容写入→分批按稳定ID回填→校验数量、hash、精确分数→增加约束→切读→观察→独立contract迁移。每步记录SQL、预期/实际计数、耗时和应用兼容版本。旧规则版本按现存Term.scheme生成标记legacy的首版本，不能伪造不存在的历史版本；现有成绩没有历史来源时显式标记回填时点。任何无法映射的旧人员/组织记录阻断相关约束，禁止删记录或猜ID。
