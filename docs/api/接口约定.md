# API 契约与兼容策略

更新：2026-10-23。机器可读的当前契约只有 [openapi.current.yaml](openapi.current.yaml)，来源于现有 Route Handler，覆盖范围见[已核查接口与兼容边界](已核查接口与兼容边界.md)。目标增量契约以[学院流程增量契约](学院流程增量契约.md)、[本轮页面接口约定](本轮页面接口约定.md)和[缺口修复接口约定](缺口修复接口约定-2026-10-20.md)记录；目标 OpenAPI 尚未单独建立，未实现的 operation 不得被当作可调用入口。关联 ENT-01～18。

## HTTP 与身份

使用同源 HTTPS、现有 NextAuth JWT cookie + AuthSession 实时校验。客户端通过 NextAuth signIn/signOut 获取/撤销会话，凭据回调遵循其CSRF流程，不自行构造无保护登录。业务写入要求 Origin 与请求 URL 同源，或精确匹配 NEXTAUTH_URL / APP_TRUSTED_ORIGINS；本机回环地址同协议同端口自动互认。代理改写请求 URL 时必须固定 NEXTAUTH_URL 或 APP_TRUSTED_ORIGINS，不采信任意 Forwarded 主机。cookie Secure/HttpOnly/SameSite由生产认证配置核验。跨站凭据访问不开放CORS。所有私有读取/写入响应 private,no-store，公开品牌资源以hash版本缓存。

业务日期UTC传输，日期选择器显示Asia/Shanghai并明确转换。十进制全部使用字符串，禁止用JSON number传精确分数；请求revision为非负整数。分页目标统一 page=1、pageSize=20（1..100）、q≤80、sort白名单加id稳定次排序，响应 `{items,total,page,pageSize}`。当前账号、活动、认定列表已按每页20条分页并返回 `{items,total,page}`，尚未回传 `pageSize`；学期列表仍无分页，是现状缺口，不伪装已统一。

## 错误与并发

当前错误为 `{error:string}`，400校验/计分、401会话、403来源/权限、404不存在、409修订或阶段、429限流、500通用失败；当前P2002统一文案只适用于账号唯一性，需补分类。目标兼容保留error并增 `{code,fields?:[{path,message}],requestId}`。稳定码：VALIDATION_ERROR、UNAUTHENTICATED、FORBIDDEN、NOT_FOUND、REVISION_CONFLICT、PHASE_CONFLICT、PREVIEW_EXPIRED、BASELINE_CHANGED、MIGRATION_REQUIRED、INCOMPLETE_RESULTS、PENDING_REVIEW、UNRESOLVED_APPEALS、FILE_REJECTED、RATE_LIMITED、INTERNAL_ERROR。不得把数据库/文件路径、堆栈、密码和token返回给浏览器。语法错误JSON应400，当前若落500须修复。

所有修改带对象revision；新增当前值型成绩/扣分用revision=null，已有对象用整数；不接受无revision覆盖。周期锁→对象写入→审计为固定顺序；账户管理锁与周期锁不得反向嵌套。目标幂等键 `Idempotency-Key` 为8..128可打印ASCII，作用域actor+operation+key并保存请求规范hash。同键同载荷返回原资源与replay=true，异载荷409；处理中202+resourceId；不把一次性密码存进幂等响应。三类导入当前以持久batchId实现提交重放，无通用幂等键；创建/上传当前尚无跨请求幂等保证。

长计算返回202与runId，GET任务返回state/processed/total/errorCode；取消只对未APPLIED任务，已生效走新更正。候选准备不能持有周期锁跨整个批次；最终切换持短锁核对规则/输入/范围修订，冲突不自动重算并生效。

## 上传、模板与导出

当前证明为原始二进制POST `/api/evidence`，头 `X-File-Name` 用encodeURIComponent编码，最大5MiB，真实签名PNG/JPEG/PDF；返回id/name/mime/size。下载只走授权 `/api/evidence/{id}`，Content-Disposition attachment、nosniff、sandbox、no-store。不能将storageKey作为URL。目标隔离/扫描不完成前不可宣称恶意文件检测已具备。

当前导入为multipart/form-data，总请求上限由boundedForm限制、文件1MiB、1..100数据行、≤30列。action=columns读取表头，preview携列映射与业务范围，commit只携batchId及必要termId。三个preview为15分钟，错误整批拒绝，snapshot变化409。账号提交只首次返回credentials，重放返回空数组；应在对话框一次性交付并提示妥善保存。

目标模板GET `/api/import-templates/{kind}`，kind=accounts/participations/grades，CSV UTF-8 BOM，可选受控XLSX。响应附templateVersion、字段说明下载链接，示例学号保持文本；字段说明为产品业务文案。导出固定resultSetId/scopeId，字符串以 `= + - @ Tab CR` 等危险前缀开始时写入明确文本单元格/CSV转义，不执行公式，数值列由系统类型写入。导出与页面同一排名服务，超过同步容量生成授权下载任务，地址不能绕过会话。

## 版本与迁移

现有action型接口继续复用同一服务，目标资源化接口分阶段加入；不建立两套计分/授权。OpenAPI operation的x-implementation取current/target，只有代码和测试证据齐备后切current。每次接口变更同步schema、页面调用、测试与追溯表；不从目标文档生成“已完成”统计。NextAuth协议作为外部库管理的边界，在当前清单列通配路由，不假造其所有响应schema。

契约核验按 [OpenAPI 3.1.1](https://spec.openapis.org/oas/v3.1.1.html) 的Schema/Reference/RequestBody语义，HTTP状态按 [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)；本项目的code/revision/snapshot是应用契约，不是这些标准替项目定义的业务行为。核验日期2026-10-20。
