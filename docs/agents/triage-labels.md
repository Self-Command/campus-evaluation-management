# Triage Labels

本地任务使用以下默认分流标签，记录在文件顶部的 `Status:` 行。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估和分类 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给 AI 执行 |
| `ready-for-human` | `ready-for-human` | 需要由人实施 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提及某个分流角色时，使用本表对应标签。
