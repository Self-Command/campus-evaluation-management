# 学校参考表原始公式核查

2026-10-19。只读核查，原文件未修改。不包含学生姓名、学号或个人分数。以下数值案例均为模拟输入。

## 1. 核查范围

用户提供的《2024-2025学年上期综合素质测评成绩细则总表》，工作表“22学1”，A1:AJ55。直接提取旧式XLS内的BIFF公式，包含566条公式记录和22组共享公式，已将共享公式展开为对应单元格表达式。

全部566个数值缓存与独立重算一致；这表示读取到了表内当前公式，不能据此认定所有公式符合表头制度。现有51个数据行的学校模板结果与AI列缓存一致，其中只有1行存在非零输入，因此进一步进行了模拟边界核对。

## 3. 需要单独说明的原表问题

### 3.1 AE列汇总在不同数据行不一致

AE5:AE7使用三个工程小计之和，AE8:AE55使用`SUM(P8:AD8)`随行平移。后者把子项原始分、小计和若干比例分一起相加，重复计分。

模拟输入：仅P列为10，其余输入为0。

| 计算位置 | 结果 |
|---|---:|
| 原表第5行AI5公式 | 2.00 |
| 原表第8行AI8公式 | 4.00 |
| 一致的“三工程封顶后合计×20%”规则 | 2.00 |

不能把这种由行号决定的差异作为统一学校评分规则写入系统。

### 3.2 部分小计公式没有填到后续行

AC列只在AC5有工匠小计公式；AC6:AC55没有相应公式。H、I、N、T等部分小计或比例公式也只有首个数据行存在，不能假设后续行一定会自动计算。

模拟输入：仅Z列为50，其余输入为0。工匠工程按40封顶后贡献8分；原表AI5算8.00，而AI6因缺AC6小计算0.00。通用评分模板对每名学生运行同一配置，不依赖某一行是否手工填了公式。

### 3.3 红色文化100分上限未被公式执行

表头明确100分上限，但O列直接使用D:G之和。模拟D列为150、其余输入为0，原表AI5为12.00；按表头封顶后应为8.00。本校模板按表头设置100分上限，并将这个差异显式记录。

### 3.4 原表未设置最终0分下限

AI列直接减AH，没有`MAX(0,...)`。模拟正向成绩为0、扣分为5，原公式结果为-5.00。本校模板不自行改成0；如果学校实际规定最低0分，可在通用配置的总分节点明确启用0分下限。

## 4. 适配口径

首版预置模板覆盖该表的分类、直接累加、内部与外层加权、100／30／30／40节点封顶，以及总分后100%扣分。模板不复制原表的漏填及重复汇总错误，也不将本表缺少的活动单次分值和违纪单次扣分数值凭空填入。

因此，“支持该表所表达的评分机制”和“逐格复刻这个文件的全部公式行为”是不同验收目标。当前按前者补齐；正式投用前应由学校核准该口径，尤其是红色文化上限和总分最低值。
