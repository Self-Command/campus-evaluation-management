# 使用 TypeScript 与 Next.js 构建单项目应用

2026-10-19，用户在比较快速开发方案后，明确选择 TypeScript 与 Next.js：页面和服务端业务放在同一个项目中，复用 shadcn/ui 的组件与后台布局。该选择符合用户采用国外主流技术、由 AI 完成开发并控制业务复杂度的目标；通用评分功能保持独立，通过明确输入输出进行验证。交付目标为生产版本，当前部署于本机／局域网演示；账号由管理员统一创建或批量导入，学生使用学号和密码登录。部署与持久化决定另见 [ADR-0002](0002-local-production-deployment.md)，依赖组合记录在技术方案与正式规格中。
