# 周期管理、评分列表与登录设置改造

2026-10-20。用户已批准先写方案再实施。本方案覆盖旧评分目录/树形编辑器的表现形式，不改变评分算法、每周期一套制度、原发布及快照不可变规则。学院审核后续批次仍按统一审核规范实施。

## 周期管理

- 保留原周期稳定ID及业务阶段，额外区分正常、已归档、已作废、回收站；不物理删除周期、材料或审计。
- 名称错误可以改名；名称去除首尾空白，同名正常周期提示冲突。复制周期只复制评分制度，不复制学生、成绩、活动、申请、材料、审核、确认或快照。
- 只有配置阶段且没有活动、项目/申报、成绩、扣分、导入批次、发布、快照、更正及异议等业务引用时可移入回收站；允许恢复。仅保存评分规则不阻止删除。
- 配置或录入审核阶段，且从未发布或结算的周期可以有理由作废；停止所有后续业务写入，记录和材料仍可授权查询。已有发布或结算历史不允许作废/删除，沿用理由更正。
- 锁定周期可以归档及取消归档。归档不替代结算锁定；历史仍可授权查询。
- 只有管理员操作；操作前显示真实引用计数，提交携revision，周期事务锁下重新鉴权、复核状态、引用和修订，写审计。回收站周期不能通过旧URL或API继续读写业务。
- 列表按正常/归档/作废/回收站筛选；默认周期自动选择排除非正常周期，明确进入历史周期时保留查询能力，切换后不沿用失效周期。

## 评分制度列表

- 使用指定完整模板的users名录表、invoice字段/预览、profile详情结构改造。用户明确授权由旧双栏树目录调整为可展开的分组列表及模块设置弹窗；不得自建另一套视觉体系。
- 综合总分由系统维护；先添加大模块，再为可汇总模块添加子模块。列表支持展开/折叠所有层级，每行呈现名称、来源或汇总方式、占上级比例、封顶/折算、必填及配置状态，不只展示名称。
- 管理员点击设置，在Dialog内编辑适用于当前模块的完整规则；常用规则直接显示，特殊规则可展开，已启用的规则始终在列表明确摘要。百分比以百分数输入，保存时明确转换。
- 支持同级排序、移入其他汇总模块、提升为大模块；父模块移动时带走全部下级，稳定ID及引用保持。拖放明确区分放到前/后和移入，不靠模糊横向偏移猜目标。手机及键盘可用“移动到”弹窗完成相同操作。
- 阻止根节点移动、循环、自身/后代挂接、将输入节点作为父级。移动后显示受影响父级比例合计及错误，不擅自平均或修改权重。允许草稿中间状态，保存/生效前必须完整校验。
- 删除存在下级或已有引用的模块必须阻断并说明原因。正式生效后只能有理由预览影响并更正，拖动不能立即改变学生成绩；旧发布与快照不改。
- 其他角色沿用同源折叠列表，以规则明细阅读方式展示完整制度，不显示禁用的编辑表单。学院/辅导员只提供已有真实授权操作；不以本批UI声称两级审核已经完成。

## 四类身份登录

- 按用户最新决定使用角色下拉，默认学生，顺序为学生、辅导员、二级学院、管理员；保留模板登录页布局及全站主题，切换保留账号、清除密码及错误，提交选定role。
- 服务端以真实账号角色校验入口，选择角色不能获得权限；错误账号、密码、角色统一返回失败，不泄露账号存在性。兼容无role的已有客户端，历史PUBLISHER可通过二级学院入口登录但不改变其旧权限。
- 不新增注册、社交登录、假演示账号。另按用户要求创建一个本机辅导员测试账号，不修改旧密码、不绑定或迁移现有学生。初始密码仅存本机未跟踪的凭据文件，首次登录必须修改。
- 登录必须校验本地生成的5位随机英文字母图片，不依赖境外或第三方验证码服务。忽略输入大小写；5分钟过期、一次提交即失效，可主动刷新，失败自动换题。服务端只保存带密钥的摘要，图片使用字形路径而非直接嵌入答案文本；不在响应、日志或HTML中额外返回答案。
- 管理员系统设置新增“登录失败限制”，默认关闭，可配置连续失败次数（1–100）及锁定分钟数（1–1440）。达到次数后按账号暂时限制登录；有效登录清零，锁定到期重新计数，调整策略后使用新策略重新计数。无效/过期验证码不计入账号失败次数，避免无成本锁定他人。角色错误与密码错误均算失败，同一账号跨角色共享次数；已登录会话不受此设置追溯影响。关闭该设置不取消基础全局请求容量保护。
- 验证码和失败状态持久化于数据库，支持服务重启及多个进程；锁定判定、失败递增和会话创建在事务及账号锁内完成，避免并发绕过。未知账号采用相同失败状态和提示，不暴露账号是否存在。

## 系统设置保存

- 排查并修复品牌信息和主题无法保存；保存应覆盖两个页签当前草稿，理由可见、校验可定位，失败保留输入，成功展示反馈及最新revision。
- 保留管理员鉴权、同源保护、revision冲突及审计。保存后读取数据库确认持久化，登录和后台同步应用站点信息与主题，不通过弱化校验解决问题。

## 实施接口约定

- GET /api/terms?view=normal|archived|void|deleted|all：默认normal；回收站及all仅管理员。页面服务listTerms默认返回非回收站周期以支持明确历史查询，自动选择仅NORMAL。
- GET /api/terms/{id}：管理员读取周期及真实usage摘要，包含canDelete/canVoid/canArchive。
- PATCH /api/terms/{id}：{action: rename|delete|restore|void|archive|unarchive, revision, reason, name?}；全部需要理由，rename需要name。
- POST /api/terms：保留name/template，新增sourceTermId可选，复制源必须可访问且不在回收站。
- 周期新增disposition（NORMAL/ARCHIVED/VOID/DELETED）、dispositionReason及dispositionAt；修改递增revision。
- GET /api/auth/captcha：no-store，返回{id,image,expiresAt}；登录增加captchaId/captcha，缺失或过期拒绝登录。设置增加loginFailureLimitEnabled、loginFailureMaxAttempts、loginFailureLockMinutes，旧设置缺失字段按关闭/5次/15分钟兼容。
- 评分继续使用save/activate/preview及既有correction接口；模块移动共用纯数据函数，不引入任意公式或第二计算器。

## 验证和保护

仅命令行类型、lint、构建、隔离集成和隔离生产HTTP检查。用户自行浏览器验收，agent不操作浏览器/电脑。迁移先逻辑备份、临时恢复逐字段核对，再增量部署；不seed覆盖、不改旧密码、不删除附件、不提交推送。必须分别记录已完成、失败及未验证项。
