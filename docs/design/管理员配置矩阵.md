# 管理员配置矩阵

更新：2026-10-24。来源：`src/lib/settings-schema.ts`、`src/server/settings.ts`。本表描述当前已实现的站点设置；草稿/发布分离、公开分享、导航定制等仍属延后目标，见[管理员设置中心](../features/15-管理员设置中心.md)及[登录页与主题个性化设计](登录页与主题个性化设计-2026-10-24.md)。

## 1. 读写权限

| 动作 | 接口 | 主体 | 说明 |
|---|---|---|---|
| 公开读取 | `GET /api/settings/public` | 匿名 | 只返回站点名称、说明、标题、主题默认值、Logo/背景资源标识与登录公告的显式白名单，不含 `revision`、登录策略或附件策略 |
| 管理读取 | `GET /api/admin/settings` | ADMIN | 完整设置与 `revision`；未改密会话返回 401 |
| 保存 | `PUT /api/admin/settings` | ADMIN | 严格 schema，必须携 `revision` 与 2–500 字理由；修订不符返回 409 |
| 上传品牌图 | `POST /api/admin/brand-assets` | ADMIN | 默认 `brand`：PNG/JPEG/ICO，≤1MB，≤4096×4096；`login-background`：PNG/JPEG/WebP，≤5MB，≤8192×8192；总数最多 200 个 |

保存与上传均在 `adminTransaction` 内复核会话、角色与 `authVersion`，并写 `AuditEvent`（`SETTINGS_CHANGED`、`BRAND_ASSET_UPLOADED`）。其他角色只读公开子集。

## 2. 字段矩阵

| 字段 | 类型与范围 | 默认值 | 生效位置 | 校验与联动 |
|---|---|---|---|---|
| `siteName` | 字符串 1–40 | `序衡` | 全站品牌名、登录页 | 去首尾空格；为空拒绝 |
| `siteDescription` | 字符串 1–160 | `高校综合测评管理` | 站点说明、metadata description | 同上 |
| `pageTitle` | 字符串 1–80 | `高校综合测评管理` | 浏览器标题、页面 metadata | 同上 |
| `themePreset` | 枚举：`default`、`brutalist`、`soft-pop`、`tangerine`、`vercel`、`claude`、`t3-chat`、`supabase`、`mono` | `default` | 站点默认配色 token；个人可在登录页/顶栏覆盖 | 只接受预设；旧值（如已下线的 violet/blue）读取时回退 `default`，写入仍严格校验 |
| `defaultThemeMode` | `light` / `dark` / `system` | `light` | 未选择个人偏好的页面默认深浅模式 | 个人 cookie 优先；公开接口返回；非法值拒绝 |
| `logoAssetId` | 可空字符串 ≤100 | `null` | 登录页、改密页与侧栏 Logo | 必须是已存在的 `BrandAsset`，否则拒绝保存 |
| `logoSize` | 整数 16–128 | `28` | 侧栏、登录页、改密页与设置预览的 Logo 显示边长（px） | 侧栏折叠时最多显示 32px；旧设置缺失时按 28 读取 |
| `faviconAssetId` | 可空字符串 ≤100 | `null` | favicon 与图标 | 同上 |
| `loginBackgroundAssetId` | 可空字符串 ≤100 | `null` | 登录页与改密页全屏背景 | 必须是已存在的 PNG/JPEG/WebP 品牌资源；保存事务内复核 |
| `loginNotice` | 字符串 0–200 | 空 | 登录卡片公告（纯文本，保留换行） | 公开可见；不支持 HTML/链接；超长拒绝 |
| `loginFailureLimitEnabled` | 布尔 | `false` | 登录失败限制总开关 | 变更后清空旧锁定状态 |
| `loginFailureMaxAttempts` | 整数 1–100 | `5` | 触发锁定的失败次数 | 与开关、锁定分钟数一并变更时清空旧锁定 |
| `loginFailureLockMinutes` | 整数 1–1440 | `15` | 锁定时长（分钟） | 同上 |
| `activityAttachmentMaxFiles` | 整数 1–20 | `5` | 每个活动附件数量上限；上传接口与编辑器实时读取 | 修改后新上传立即按新值限制，已存在附件不删除 |
| `activityAttachmentMaxSizeMb` | 整数 1–50 | `10` | 单个活动附件大小上限 | 上传接口在读取请求体时按新值截断并拒绝 |
| `activityAttachmentAllowedExtensions` | 字符串数组 1–20 项 | `png,jpg,jpeg,webp,gif,pdf,doc,docx,xls,xlsx,ppt,pptx,zip,txt,md` | 活动附件后缀白名单 | 每项为小写字母数字、1–10 位、不含点；实际类型还须通过真实签名校验 |

## 3. 品牌资源约束

- 站点标识仅接受真实签名可识别的 PNG、JPEG、ICO；登录背景仅接受 PNG、JPEG、WebP；不接受 SVG、HTML、外链或任意脚本资源。
- 站点标识单文件 ≤1MB、宽高 ≤4096；登录背景单文件 ≤5MB、宽高 ≤8192；总数上限 200，超出提示复用已有图片。
- 存储 `sha256`，读取时重新校验，不一致返回 500，不返回损坏内容。
- 登录背景只有被站点设置引用时才允许匿名读取；未被引用的资源仍需管理员会话。
- 已被设置引用的资源不能通过删除设置之外的方式移除；历史引用不立即物理删除。

活动附件存储于 `ACTIVITY_ATTACHMENT_DIR`（默认 `.local/activity-attachments`），数据库只保存元数据、SHA-256 与随机存储键；上传时同时校验白名单后缀和真实文件签名。超过24小时仍未绑定活动的附件由 `npm run cleanup:attachments` 清理，已绑定附件的数据库记录随活动级联删除；存储文件不随级联自动回收，删除活动前应通过删除接口清理。

## 4. 未纳入当前矩阵

以下能力尚未实现，不得在页面或验收中当作已有配置项：

- 设置草稿/发布/历史恢复与多版本回滚。
- 公开分享页、分享图与 SEO 自定义。
- 导航标签、菜单顺序与角色路由定制。
- 计分规则、模块权重、扣分项目的可视化配置（属于周期与评分制度，不在站点设置内）。
- 运行密钥、数据库连接、邮件与短信配置（只通过环境变量管理，不进入业务页面）。
