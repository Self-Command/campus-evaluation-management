# 高校综合测评管理

面向正式使用的高校综合测评系统。交付目标是核心业务可靠、流程完整，不以平台化功能数量或全部功能最优作为首次交付前提。技术栈保持现有Next.js、React、TypeScript、shadcn/ui Base UI、Prisma、PostgreSQL及NextAuth，不另起项目。

## 实施与保护边界

- 仅按完整模板原页改造正式前端，直接接入真实授权服务；缺少的后端补最小可靠实现，不放假按钮、虚构统计或未实现导航。
- 按最新规范增量实施四类身份、学院/班级范围和必要两级审核；每周期仍一套生效制度，多方案匹配、通用权限/审批平台、任务平台及复杂设置审批延后。角色迁移不改原密码，不伪造历史审批。
- 不清库、不改已有账号密码、不删除证明或运行所需模板，不输出`.env`、密码或令牌。2026-10-20 用户明确授权创建 GitHub 仓库并提交、推送当前成果；本次保存代码、文档、测试及迁移，不上传真实凭据、数据库、附件、历史 UI 备份或本地运行文件。后续 GitHub 写操作仍按用户授权执行。
- 本轮用户已授权一个UI agent直接开发页面，主负责人负责后端及对齐；用户自行界面验收。按需直接用本地`gh`核查实现、许可证及兼容性，不运行不可信仓库脚本。
- 每批如实报告实现与验证。历史测试通过不代表新前端完成；部署、备份恢复、构建、生产运行和Docker验收分开记录，Docker实际部署仍暂缓。
