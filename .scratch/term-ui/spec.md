# 周期和制度交互改造

Status: ready-for-human

用户已批准，正式方案见[周期与评分列表改造方案](../../docs/design/周期与评分列表改造方案.md)。本批优先于学院后续审核开发，但不改变后者目标。

顺序：01周期治理后端及迁移保护；02模板列表/弹窗/拖动及只读制度；03四角色入口与辅导员账号；04设置保存故障；05隔离验证、迁移与记录。一个UI agent负责前端，主负责人负责后端、对齐和验证。

验收：无引用草稿可删除恢复、有引用拒删、作废禁止写入、归档历史可读、并发修订冲突；模块拖移保留ID/子级且拒绝循环和输入父级、比例错误阻止生效；角色入口不改变权限；设置两个页签保存持久化并更新全站；旧数据密码附件保护。

## Comments

用户最新补充：角色改下拉，默认学生并排第一；本地一次性英文图片验证码；系统设置可关闭/自定失败次数与限制分钟数。与本批一起实现并进行隔离并发及HTTP校验，不用第三方境外资源，不提供验证码绕过开关。
