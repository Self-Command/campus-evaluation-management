# 04 成绩扣分审核与更正

辅导员在授权班级录入/导入成绩、事件扣分，学院通过才生效；普通退回原辅导员并必填理由，修正新修订或放弃。新修订未通过前保留原有效值，不同扣分事件不覆盖，同事件不重复扣分；阶段、权限、并发与旧发布保护沿用。

验收：待审不影响总分、一次生效、退回/重提/放弃、覆盖与撤销历史、班级学院隔离、锁定及更正竞态。
