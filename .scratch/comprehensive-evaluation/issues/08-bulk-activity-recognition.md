# 08: 活动名单导入与共享证明

**What to build:** 发布者上传多人活动名单与一份共享证明，预览并提交后由管理员认定，名单内学生各自看到本人记录且重复名单不会重复加分。

**Blocked by:** 07 单人参与证明、审核与计分查询。

**Status:** in-progress

## 实施证据（2026-10-20）

- 已接入CSV/XLSX名单、学号列映射、共享证明、服务端预览及15分钟批次、学生/活动/参与快照复核和事务提交。
- 唯一活动+学生事实；重复文件行、已有有效认定和本人待审来源可解释跳过；重复批次响应不重复写入，名单分值列不参与计分。
- 数据库验证错误整批拒绝、并发幂等、批次归属与共享证明授权；浏览器验证发布者名单→管理员单条审核→学生3分。
- 待补：管理员明确选中批量审核及逐条结果、未引用临时证明清理、关联更正和并发变化的完整专项测试；本项未全部完成。

**Spec coverage:** US-028、029、030、031、032、033、041、048、051、054、075、077、078、079；D-03、D-09、D-10、D-11、D-13；AC-06、AC-09、AC-13。

- [ ] 支持活动 CSV／XLSX 名单上传、列对应、服务端预览和确认，按学号准确匹配已有学生，保留前导零并定位错误行。
- [ ] 预览区分新增、已有参与和非法行；任一错误阻止正式批次写入，重复行可解释地跳过或合并，文件携带分值不改变统一活动分数。
- [ ] 提交重新检查发布者归属、学期状态和预览版本，重复点击、请求重试与并发导入不产生重复参与。
- [ ] 批次写入使用事务，失败不遗留半批参与；管理员按记录审核并查看逐条结果，只有有效认定进入计算。
- [ ] 一份共享证明可被多名参与者引用，每名学生只能查看本人关联和被授权材料，不能借此查看同批学生个人记录。
- [ ] 删除或更正某条关联不会破坏其他有效引用，失败上传和无引用临时材料可安全清理。
- [ ] 学生结果与单人认定沿用相同评分和明细契约，达到上限的参与记录仍保留。
- [ ] 真实数据库和浏览器验证多人导入、共享证明、审核、学生查看，以及错误回滚、重复名单、并发提交和越权读取。
