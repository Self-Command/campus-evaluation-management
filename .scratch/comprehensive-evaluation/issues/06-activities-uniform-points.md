# 06: 活动展示与统一分值确认

**What to build:** 发布者在页面建立本人活动并提出所属模块与统一原始分，管理员确认评分配置后学生可浏览活动信息，发布者只能维护自己负责的活动。

**Blocked by:** 04 学期与基础评分树配置。

**Status:** ready-for-agent

**Spec coverage:** US-024、025、026、027、032、054、075、076、078、079；D-03、D-04、D-05、D-09；AC-02、AC-06。

- [ ] 发布者能建立、编辑和查看本人活动，学生能浏览活动名称、组织者、时间、内容与参与要求，系统不产生在线报名业务。
- [ ] 活动绑定当前学期的活动累加最底层模块，发布者提出统一原始分，管理员确认归属与分值并记录处理依据。
- [ ] 服务端拒绝绑定汇总模块、成绩输入模块或其他方案节点，以及无效分值和未授权修改。
- [ ] 统一分值不因名单里的不同学生而变化，客户端携带的逐人任意分值不能成为正式评分依据。
- [ ] 发布者能查看自己的提交状态和管理员反馈，但不能通过替换活动标识查看或修改他人管理数据。
- [ ] 活动页面、管理员确认页面和数据库状态一致；学期状态与权限由服务端检查，变更保留日志。
- [ ] 通过真实角色、数据库和浏览器验证发布、确认、展示及越权拒绝；未确认分值的活动不能绕过确认流程进入有效加分。
