# 10: 成绩录入、导入与完整结果查询

**What to build:** 管理员手工录入或通过 CSV／XLSX 导入学业、体育等成绩，预览变更后提交；学生能查看包含这些输入的完整综合成绩，缺失输入仍明确显示待录入。

**Blocked by:** 05 学校模板、通用计分与试算明细。

**Status:** in-progress

## 实施证据（2026-10-20）

- 已实现 `GradeInput` 唯一当前值、修订检查、手工录入与理由审计；`GradeImport` 服务端预览、15分钟有效期、快照复核、整批事务与重试幂等。
- `/grades` 提供真实查询、单项保存、CSV/XLSX列映射、差异预览与确认；`/results` 读取真实成绩，必需缺失与零分分别处理。
- `tests/integration/activities.test.ts` 覆盖范围、来源、角色、相同值、覆盖、过期数据与并发批次；`tests/e2e/activities.spec.ts` 覆盖手工80分、批量改90分及学生结果同步。
- 最新全量26项数据库测试、10项浏览器测试、类型检查、lint、生产构建通过。尚需补充成绩XLSX专属端到端及更完整故障注入证据，不将本项所有验收提前勾选。

**Spec coverage:** US-020、029、043、044、045、046、048、049、050、052、053、054、075、077、078、079；D-03、D-07、D-10、D-12；AC-04、AC-08、AC-09、AC-13。

- [ ] 管理员在当前学期的成绩输入最底层模块录入数值，或上传 CSV／XLSX、对应列并预览，不能把汇总或展示列当作重复原始输入。
- [ ] 按唯一学生标识匹配，服务端校验模块来源、数值有效范围及必填项，超范围值明确拒绝而不通过封顶掩盖。
- [ ] 同学期、学生、成绩模块只有一个当前有效值；预览区分新增、相同值和覆盖差异，覆盖经确认并保留记录，重复导入不累加。
- [ ] 错误行阻止该批写入，预览与提交同规则并在提交时重新校验权限、学期状态和版本；过期预览不覆盖新修改。
- [ ] 批次事务、唯一约束与重复提交保护阻止半批写入或丢失更新，处理数量与错误可定位。
- [ ] 有效成绩更新后统一契约重算，学生页面显示新输入与明细；明确录入零分和必需成绩缺失产生不同完整性状态。
- [ ] 真实数据库测试范围错误、重复及覆盖、并发与回滚，浏览器走通手工录入、批量预览提交和本人完整结果查询。
