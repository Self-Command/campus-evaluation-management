# 17: 生产版本端到端验收与演示交付

**What to build:** 在完整生产部署中，用虚拟学校数据走通建号、配置、活动与个人认定、成绩和扣分、核对异议、排名锁定、导出及恢复，交付可复现的检查与演示说明。

**Blocked by:** 03 学生账号批量导入；08 活动名单导入与共享证明；16 生产数据备份与隔离恢复。

**Status:** ready-for-agent

**Spec coverage:** US-001至082；D-01至D-14；AC-01至AC-16。

- [ ] 汇合所有功能分支，在生产构建与真实 PostgreSQL 中按三角色走通完整业务，演示数据为虚拟数据且不泄露实际账号秘密。
- [ ] 从首次改密开始，覆盖模块配置与试算、多人共享证明认定、个人申报去重、成绩与扣分输入、学生核对异议、排名、锁定、更正及 Excel 导出。
- [ ] 验证不同导入在核对／锁定状态、会话失效、重复请求及并发操作下遵循同一规则，用户可见状态与持久结果一致。
- [ ] 综合检查共享附件引用、跨用户与跨角色访问、公式文本、非法上传及输入错误等边界，修复发现的问题并保留回归证据。
- [ ] 在具备批量账号和共享证明的完整数据集上重复重启与隔离恢复，核对所有引用和锁定成果，补齐早期恢复样本未覆盖的场景。
- [ ] 类型检查、代码检查、相关自动化测试和生产构建通过并纳入持续验证；每个先前任务的测试继续执行，不把测试工作集中推迟到本任务。
- [ ] 记录实际环境、学生／活动／模块数量、并发操作及结果，声明已验证容量和边界，不以算法深度样例宣称界面无限容量。
- [ ] 提供完整启动、迁移、初始化、备份恢复、虚拟数据准备及演示步骤，使维护者能在当前本地环境复现生产版本。
- [ ] 对照全部用户故事及验收项提交运行证据，未通过项明确列出并修复；仅静态检查通过或容器启动不能作为完整验收。
