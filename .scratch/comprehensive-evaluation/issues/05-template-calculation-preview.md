# 05: 学校模板、通用计分与试算明细

**What to build:** 管理员套用学校模板或编辑通用计分参数，在页面输入样例并查看逐层试算；学生能查看本人当前结果及必需成绩待录入状态，为后续认定和成绩输入提供统一计算入口。

**Blocked by:** 04 学期与基础评分树配置。

**Status:** ready-for-agent

**Spec coverage:** US-011、017、018、019、020、021、046、049、050、051、052、053、054、079；D-02、D-05、D-06、D-07、D-08；AC-03、AC-04。

- [ ] 管理员可套用本校配置，并编辑任意节点上限、可选满分折算、扣分位置与系数、可选最低分；所有名称和参数为配置数据。
- [ ] 独立评分公开契约接收合法树、原始输入、扣分与显示精度，返回完整性状态、缺失项、总分及逐节点计算明细。
- [ ] 按原始输入／子项汇总、节点封顶、可选折算、节点扣分、可选下限的顺序迭代求值，每个父级只接收直接子项结果。
- [ ] 本校模板按基础内部10%／80%／10%、基础外层80%、发展三工程封顶后直接相加乘20%、总分后扣分实现；保留100／30／30／40上限、不自动归一化、不默认零分下限。
- [ ] 十进制计算、中间不提前按两位小数舍入；最终显示两位小数，模板输入错误和缺失必需成绩明确定位。
- [ ] 试算页面展示封顶前后、折算、扣分与父级贡献，学生本人结果入口使用同一评分契约；不同身份不能读取他人结果，未有活动时为零而缺失必需成绩为待录入。
- [ ] 保存结果修订依据与统一读取契约，为后续真实业务输入和学生核对提供一致结果，不发布失败或混合口径计算。
- [ ] 正式计算实现通过学校固定样例、独立随机控制公式、另一套模板、折算／下限／扣分边界、错误树和深层树测试；现有 Python 验证不替代新实现测试。
- [ ] 浏览器可完整执行套用模板、配置参数、试算和查看明细，声明样例验证规模而不声称界面无限容量。
