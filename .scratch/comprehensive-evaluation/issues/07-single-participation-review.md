# 07: 单人参与证明、审核与计分查询

**What to build:** 发布者为一名学生提交活动参与和证明，管理员在页面审核，学生随后查看本人参与事实、授权证明与计分明细，走通活动认定到成绩的首条完整链路。

**Blocked by:** 05 学校模板、通用计分与试算明细；06 活动展示与统一分值确认。

**Status:** ready-for-agent

**Spec coverage:** US-030、031、032、033、038、039、041、042、049、050、051、052、054、075、076、077、078、079；D-03、D-04、D-07、D-09、D-11、D-13；AC-02、AC-04、AC-06、AC-09、AC-13。

- [ ] 发布者为本人活动选择已有学生并上传证明后提交待审核参与记录，管理员能查看事实、材料、归属和统一原始分。
- [ ] 待审核及不予认定不计分；通过后按已确认统一分值计入当前学生原始输入并使用通用契约重算，拒绝或更正记录原因和操作者。
- [ ] 同活动同学生的有效参与受数据库唯一约束保护，重复提交或并发审核最多形成一次有效贡献；审核失败不留下已加分但无有效认定的状态。
- [ ] 证明上传检查允许类型、实际格式、大小和数量，使用受控标识保存到持久目录，不能指定任意存储路径或作为可执行页面访问。
- [ ] 学生通过鉴权接口查看本人记录的材料；发布者仅访问本人活动材料，未登录和其他学生不能通过可猜测链接获得文件。
- [ ] 学生看到活动、认定状态、统一原始分、逐节点结果与实际增量解释；达到上限仍保留事实，不把必需学业或体育缺失当成零。
- [ ] 管理员可处理明确选中的记录并查看逐条结果，批量界面不掩盖失败；操作与原始认定依据可追溯。
- [ ] 浏览器走通发布者提交、管理员审核、学生查看，真实数据库测试重复提交、并发认定、失败回滚、封顶及跨身份文件访问。
