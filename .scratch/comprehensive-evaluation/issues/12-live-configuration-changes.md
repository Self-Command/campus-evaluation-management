# 12: 生效规则变更、数据迁移与统一重算

**What to build:** 管理员调整生效模块、参数或活动统一分值前，先查看受影响人数与示例差异；确认后安全迁移已有引用并为本学期全体学生统一重算，失败不混合发布。

**Blocked by:** 09 个人加分项目、申报与事实去重；10 成绩录入、导入与完整结果查询；11 节点扣分登记与解释。

**Status:** ready-for-agent

**Spec coverage:** US-013、022、023、034、049、050、052、057、075、077、078、079；D-03、D-05、D-06、D-07、D-09、D-13；AC-03、AC-05、AC-13。

- [ ] 生效配置修改前展示变更摘要、受影响人数及示例分数；管理员确认后修改，取消预览不影响当前有效结果。
- [ ] 处理活动认定、个人申报、成绩和扣分等现有引用，阻止直接删除被使用模块或把数据切换到不兼容来源。
- [ ] 最底层继续拆分时，可在页面明确目标下级模块并迁移输入；迁移不完整、非法结构或并发冲突阻止生效。
- [ ] 通过统一契约为本学期所有学生计算，新结果完整成功后统一生效，不保留对不同学生并行生效的多套规则。
- [ ] 失败重算保留上次完整有效口径并定位错误，读取、页面与后续导出不会混合新旧修订。
- [ ] 更正活动或个人项目统一分值时预览影响并作用于全部相关有效认定，不允许逐人任意设另一分值。
- [ ] 保留修改前后、修订依据、操作者和理由，并提供结果变化标识供学生核对流程识别旧确认。
- [ ] 真实数据库及浏览器验证调整上限／比例、带记录拆分迁移、活动分值变化、失败回滚及并发冲突，校验全部输入来源的结果一致性。
