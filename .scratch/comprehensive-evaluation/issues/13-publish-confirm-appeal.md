# 13: 成绩发布、学生核对与异议处理

**What to build:** 管理员发布同一口径的成绩供核对，学生查看本人明细、确认或针对记录提出异议，管理员处理并反馈；成绩变化后旧确认不代表新结果。

**Blocked by:** 09 个人加分项目、申报与事实去重；10 成绩录入、导入与完整结果查询。

**Status:** ready-for-agent

**Spec coverage:** US-037、049、050、053、054、055、056、057、058、059、060、075、076、077、078、079；D-04、D-05、D-12、D-13；AC-02、AC-05、AC-10。

- [ ] 管理员在页面把已计算结果发布进入核对阶段；方案、结果状态和当前修订明确，不发布失败或混合口径结果。
- [ ] 学生查看本人认定、分数、证明和完整性状态，可确认结果或对具体记录／结果提交异议，不能读写他人数据。
- [ ] 学生确认绑定当时结果，输入或结果变化后旧确认可追溯但不能冒充对新结果的确认；未确认始终如实显示。
- [ ] 管理员查看异议依据、处理结论和必要更正，记录操作者与理由，学生能看到结果；失败处理不显示为已解决。
- [ ] 核对阶段限制普通申报、导入及大范围配置调整，需要时明确重新开放；权限和阶段约束在服务端生效。
- [ ] 汇总显示必需成绩缺失、待审核与未解决异议，作为后续结算的真实阻断信息而不改写成零分或已确认。
- [ ] 真实数据库测试结果变化、过期确认、并发异议处理和跨学生访问；浏览器走通发布、确认／异议、管理员处理与学生反馈。
