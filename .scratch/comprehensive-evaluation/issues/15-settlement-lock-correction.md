# 15: 学期锁定、结算快照与更正

**What to build:** 管理员解决待办后锁定学期并保存一致快照，学生与管理员查询最终成果；需要修正时填写理由重新开放、统一重算并再次锁定，历史成果仍可追溯。

**Blocked by:** 12 生效规则变更、数据迁移与统一重算；13 成绩发布、学生核对与异议处理；14 范围排名与 Excel 导出。

**Status:** ready-for-agent

**Spec coverage:** US-022、023、034、048、055、056、057、058、059、060、063、064、065、066、067、069、075、076、077、078、079；D-03、D-05、D-09、D-10、D-12、D-13；AC-05、AC-10、AC-11、AC-12、AC-13。

- [ ] 锁定前检查必需成绩缺失、待审核、未解决异议和重算状态，阻断信息定位具体学生或事项；未确认状态不伪造为已确认。
- [ ] 锁定与快照创建一致完成，保存当时方案、学生范围、有效输入依据、节点明细、最终成绩及排名；失败不显示已锁定却缺少快照。
- [ ] 锁定后通过服务端和事务阻止普通申报、名单／成绩写入、审核、扣分及规则修改，旧页面和既有预览不能绕过。
- [ ] 最终页面及正式导出读取相应快照，后续组织归属或配置变化不会改写旧成果。
- [ ] 管理员填写理由后可明确重新开放，修正后统一重算、重新发布核对并再次锁定；保留旧快照、前后差异与操作依据。
- [ ] 结果变化后旧确认与异议依据仍可解释，新结果的核对状态正确；不增加独立复核角色或多层更正审批。
- [ ] 并发锁定与业务写入、更正和重复提交不会丢失更新或产生半套成果，失败可安全重试。
- [ ] 通过真实数据库和浏览器验证阻断、锁定、过期请求拦截、快照导出及带理由更正全链路，包含恢复后可再次读取的最终成果数据。
