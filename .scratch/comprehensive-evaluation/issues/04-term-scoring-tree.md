# 04: 学期与基础评分树配置

**What to build:** 管理员建立学期，在树形页面添加、命名、排序和移动模块，指定最底层输入来源与汇总方式，保存并校验一套所有学生共用的评分结构。

**Blocked by:** 02 三角色账号与学生档案管理。

**Status:** ready-for-agent

**Spec coverage:** US-010、012、013、014、015、016、020、076、078、079；D-03、D-05、D-06；AC-03。

- [ ] 学期在配置阶段建立并关联一套方案，学院、专业和班级筛选不形成不同的学生方案。
- [ ] 页面按需展开树、显示父级路径，支持新增下级、改名、排序、移动及删除尚未被引用的模块，不写死两层、三层或五层业务限制。
- [ ] 汇总模块选择直接累加或比例汇总；比例汇总直接下级合计100%，直接累加不强制填写比例。
- [ ] 最底层模块选择活动累加或成绩录入／导入之一，配置有效输入范围和缺失政策；汇总模块不能同时直接录入原始分。
- [ ] 服务端拒绝循环、跨方案挂接、重复或游离节点、非法父子关系、空汇总与缺少输入来源的生效配置。
- [ ] 管理员在校验通过后可开启学期使用，未通过的配置保持草稿；后续活动和成绩操作能识别当前阶段与生效方案。
- [ ] 管理操作检查当前角色与学期状态，失败不保存半棵树；此任务不开放对已有业务数据的破坏性变更。
- [ ] 通过数据库和页面验证深层树保存、读取、编辑、两种汇总方式及非法结构拦截，保留能被后续试算与业务操作使用的稳定配置契约。
