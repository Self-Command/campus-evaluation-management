# 09: 个人加分项目、申报与事实去重

**What to build:** 管理员创建统一分值的加分项目，学生选择项目提交本人材料，管理员审核后形成有效认定；与已有活动参与属于同一事实时合并依据且只计一次分。

**Blocked by:** 07 单人参与证明、审核与计分查询。

**Status:** ready-for-agent

**Spec coverage:** US-035、036、037、038、039、040、041、042、049、050、054、075、076、077、078、079；D-03、D-04、D-07、D-09、D-11；AC-02、AC-07、AC-09、AC-13。

- [ ] 管理员创建加分项目并绑定活动累加最底层模块和统一原始分，学生看到项目规则后选择申报，不能自行填写正式得分。
- [ ] 学生提交本人事实与证明并查看处理状态和理由，管理员通过审核页面查看来源、材料、已有认定及评分归属。
- [ ] 待审核和不予认定不计分；通过后原子地形成有效输入并重算，更正或拒绝保留操作者、时间及理由。
- [ ] 对应已有活动参与时引用同一有效事实并补充证据；无法确定时给管理员冲突提示，不能凭重复文件直接判违规或默认新增分数。
- [ ] 支持按处理理由补充材料或重新提交，保留来源历史，重复和并发审核不产生第二次有效贡献。
- [ ] 授权、文件校验、鉴权下载与引用保护沿用同一业务契约，学生只能查看本人申报和授权证明。
- [ ] 管理员可批量处理选中记录并看到逐条结果；学生参与与成绩页面反映有效认定及失败原因。
- [ ] 真实数据库测试个人／组织双来源去重、并发审核、回滚与跨学生访问，浏览器走通项目创建、申报、审核和本人结果查看。
