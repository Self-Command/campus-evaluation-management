# 14: 范围排名与 Excel 导出

**What to build:** 管理员按学院、专业或班级查看当前完整成绩排名并导出 Excel，学生查看本人在对应范围的名次；学校展示列读取既有节点结果，不重复参与计分。

**Blocked by:** 10 成绩录入、导入与完整结果查询。

**Status:** ready-for-agent

**Spec coverage:** US-049、050、053、054、061、062、067、068、069、075、076、078、079；D-04、D-07、D-08、D-12；AC-02、AC-09、AC-11。

- [ ] 管理员可按同一学期及学院、专业、班级筛选完整学生结果，不完整学生单列并给出原因。
- [ ] 以统一对外两位小数成绩作为排序比较值，相同显示成绩并列，名次采用1、2、2、4；页面与导出采用同一口径。
- [ ] 学生仅能查看本人名次及相应范围信息，不能通过排名页面获得其他学生个人材料；服务端验证导出权限。
- [ ] Excel 包含学期、范围、当前状态、学生标识、分项、扣分、总分与名次，尚未锁定的结果明确标注。
- [ ] 本校小计、比例展示和总分列从模板数据及已有节点结果映射，不重算错误源表公式或反向成为评分输入。
- [ ] 姓名、活动名等用户文本按文本写出，处理公式前缀，防止电子表格软件把用户内容执行为公式。
- [ ] 导出读取一致结果修订并记录必要操作依据，失败不返回伪装成功的成果文件。
- [ ] 通过业务和浏览器测试范围隔离、同分及舍入边界、不完整排除、公式文本和导出内容与页面一致性。
