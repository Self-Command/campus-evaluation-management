# 03: 学生账号批量导入

**What to build:** 管理员上传 CSV 或 XLSX 学生名单，对应列并预览新增、重复和错误行，确认后一次建立学生账号与档案，并能安全获取初始密码交付信息。

**Blocked by:** 02 三角色账号与学生档案管理。

**Status:** ready-for-agent

**Spec coverage:** US-003、005、009、029、048、075、077、078、079；D-03、D-04、D-10；AC-01、AC-09、AC-13。

- [ ] 支持 CSV／XLSX 上传、列对应、服务端预览与提交，显示新增、可跳过重复行及逐行错误。
- [ ] 保留学号前导零，校验唯一学号／登录标识与学生组织字段；已存在账号不重复创建、不静默重置密码。
- [ ] 任一错误行阻止该批写入；修正后重新预览，预览和提交采用同一验证规则。
- [ ] 提交重新检查管理员权限和预览状态；并发建号、重复点击及网络重试不会产生重复账号或覆盖新修改。
- [ ] 确认批次使用事务；失败不遗留半批账号，结果清楚列出新增、跳过与失败数量。
- [ ] 初始密码沿用受控生成、首次改密与安全交付规则，明文不进入普通日志和数据库。
- [ ] 通过真实数据库测试前导零、重复学号、非法行、回滚和重复提交，并验证浏览器预览至建号流程及错误提示。
