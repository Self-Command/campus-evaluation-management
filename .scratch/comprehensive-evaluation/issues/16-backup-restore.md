# 16: 生产数据备份与隔离恢复

**What to build:** 部署维护者按照交付说明，在维护窗口备份数据库与证明文件，再在干净隔离环境恢复；用户可以登录、查看授权证明并核对原锁定成绩。

**Blocked by:** 15 学期锁定、结算快照与更正。

**Status:** ready-for-agent

**Spec coverage:** US-070、071、072、073、074、075、077、080、081；D-11、D-13、D-14；AC-14、AC-15、AC-16。

- [ ] 完善生产部署的环境配置、迁移、初始化、健康检查、更新和重启说明，操作可复现且不要求清空已有数据。
- [ ] 数据库与证明文件使用独立持久存储，容器重建与应用更新后用户、记录、材料和结算快照仍可使用。
- [ ] 首版可暂停业务写入后备份，覆盖数据库、证明文件与引用一致性，记录备份版本及必要恢复配置，不泄露秘密。
- [ ] 在全新隔离环境恢复备份，不覆盖原环境；迁移或恢复失败有明确诊断与恢复步骤。
- [ ] 恢复后的真实浏览器登录、授权材料下载、节点明细和锁定成绩与备份前一致，旧快照及修改记录可追溯。
- [ ] 证明文件缺失、数据库不可用或不一致恢复能被验证流程发现，不以容器进程存在代替恢复成功。
- [ ] 提供实际重启保留及恢复演练证据，明确本地部署的访问、代理、TLS、Cookie 和持久卷配置与验证条件。
- [ ] 本任务以维护者操作和恢复后可用的业务成果为完整交付，不把它拆成孤立的脚本或数据库层工作。
